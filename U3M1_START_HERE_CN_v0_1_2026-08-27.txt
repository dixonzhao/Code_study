U003 / U3M1 Module Foundation 执行指南
日期：2026-08-27

目标
----
建立U003模块契约、模块目录、扫描/校验器和第一个双语声明式模块。
本步骤不会修改或启动现有U003 v0.13 GUI。

下载位置
--------
把以下两个文件直接下载到：

  C-CODE\U-UDP003\04_TEMP

文件：

  UDP003_U3M1_MODULE_FOUNDATION_v0_1.zip
  u003_u3m1_module_foundation_installer_v0_1.py.txt

无需手动解压ZIP。

执行位置
--------
使用CMD，先进入C-CODE根目录。严格只执行下面三行：

  python U-UDP003\04_TEMP\u003_u3m1_module_foundation_installer_v0_1.py.txt --prepare
  python U-UDP003\01_PROGRAMS\u003_module_runtime_v0_1.py --self-test
  python U-UDP003\01_PROGRAMS\u003_module_runtime_v0_1.py --scan-root U-UDP003\02_MODULES --catalog-output U-UDP003\02_CONTROLS\u003_module_catalog_v0_1.json

执行意义
--------
第1行：核对ZIP成员和SHA-256，刷新U3M1临时解压区，安装契约与模块。
第2行：验证模块边界、版本选择、日语回退和受保护字段禁止修改。
第3行：扫描正式02_MODULES目录并生成当前模块目录表。

成功回传
--------
只需回传后两条末行：

  U003-U3M1-SELFTEST-PASS-25 C-0
  U3M1R N-M1-G1-D1-P0-J1-X0 C-0

若失败，请回传完整U3M1PE或U3M1E错误行。

预期安装结果
------------
  U-UDP003\01_PROGRAMS\u003_module_runtime_v0_1.py
  U-UDP003\02_CONTROLS\contracts\u003_module_contract_v0_1.json
  U-UDP003\02_CONTROLS\u003_module_catalog_v0_1.json
  U-UDP003\02_MODULES\REVIEW_ASSIST\CameraRadar.U003.ReviewDispositionLabels\0.1.0\...

判断
----
C-0仅表示U3M1模块基础设施成立。U003 GUI在U3M3之前不会显示模块管理界面。
