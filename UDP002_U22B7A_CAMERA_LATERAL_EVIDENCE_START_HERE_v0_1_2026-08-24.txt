UDP002 U22B7A 执行指南
Camera Lateral Evidence Profile
版本：0.1
日期：2026-08-24

一、目的

本节点只读检查现有 Golden Run：

1. 将 Camera 1 / Camera 3 的 Distance 与 LateralPosition 成对展开；
2. 对照旧 S1 canonical 选择结果；
3. 输出多组横向阈值的影响统计；
4. 为 S1 v0.3 的 geometry-assisted reacquisition 选择参数。

本程序不会修改 U001、已验收 U002 Run 或 U003 文件，也不会自动批准任何阈值。

二、文件放置

下载后，把下列程序直接放入：

U-UDP002\04_TEMP

文件：

u002_u22b7a_camera_lateral_evidence_profiler_v0_1.py.txt

三、自测

在 U-UDP002 根目录使用 CMD：

python 04_TEMP\u002_u22b7a_camera_lateral_evidence_profiler_v0_1.py.txt --self-test

预期：

UDP002-U22B7A-SELFTEST-PASS-18 C-0

四、运行

仍在 U-UDP002 根目录使用 CMD：

python 04_TEMP\u002_u22b7a_camera_lateral_evidence_profiler_v0_1.py.txt --workspace-root . --output-dir 04_TEMP\U22B7A_OUTPUT --frame-start 41380 --frame-end 41780

程序会从 07_OUTPUT 中自动选择最近一个包含
camera_target_reconstruction.csv 的完整 Run，并从冻结的 S1 request
读取原始 U001 InputPackage 路径。

五、输出目录确认

dir 04_TEMP\U22B7A_OUTPUT

应生成四个文件：

1. b7a_camera_lateral_evidence_rows.csv
2. b7a_abs_lateral_threshold_sweep.csv
3. b7a_camera_lateral_evidence_quality.json
4. b7a_return_capsule.txt

六、回传

只需要回传 b7a_return_capsule.txt 中的一行：

B7A N-F...-G...-I...-D...-S8-X0 C-0

不要手敲 CSV，也暂时不需要人工选择阈值。

若 C-7，回传终端中的 K-... 一行即可。

七、成功标准

- C-0；
- 成功精确解析 Camera 1/3 的 Distance 与 LateralPosition；
- 输出 41380–41780 的紧凑对照表；
- 输出八组阈值影响统计；
- 输入文件 SHA-256 被记录且原文件未修改。

END OF GUIDE
