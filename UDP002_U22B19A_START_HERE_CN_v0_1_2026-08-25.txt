UDP002 U22B19A 执行指南
日期：2026-08-25

一、这一步在做什么

B18 已确认 Width 值得进入 S1 正式输出接口。

B19A 只完成第一半：

1. 安装独立版本 S1 v0.4.0；
2. 给现有输出追加 4 个 Width 证据字段；
3. 在本机对照 S1 v0.3.0，证明旧字段和选择结果完全不变；
4. 使用现有 U002 qualification controller 正式验收 v0.4.0。

新增字段：

- SelectedCameraWidth
- SelectedCameraWidthValid
- SelectedCameraWidthReason
- SelectedCameraWidthSourceCanonicalName

Width 只读取当前 FrameCount、当前 SelectedCameraRole 对应的 Camera Width。
Width 不参与 Camera 选择，不跨帧保持，也不修改 v0.3.0。

B19A 不创建公司实测 binding profile，不运行 Full Golden Run。
真实 Width 绑定和实测 v0.3/v0.4 对照属于下一节点 B19B。

二、下载位置

把以下 3 个文件直接下载到：

C-CODE\U-UDP002\04_TEMP

文件名必须保持不变：

1. u002_u22b19a_s1_width_interface_installer_v0_1.py.txt
2. UDP002_U22B19A_S1_WIDTH_INTERFACE_PACKAGE_v0_1.zip
3. UDP002_U22B19A_START_HERE_CN_v0_1_2026-08-25.txt

不要手动解压 ZIP。

三、执行位置

使用 CMD，当前目录必须是：

C-CODE

四、只运行下面 3 行

python U-UDP002\04_TEMP\u002_u22b19a_s1_width_interface_installer_v0_1.py.txt --prepare --workspace-root U-UDP002
python U-UDP002\04_TEMP\u002_u22b19a_s1_width_interface_installer_v0_1.py.txt --self-test --workspace-root U-UDP002
python U-UDP002\04_TEMP\u002_u22b19a_s1_width_interface_installer_v0_1.py.txt --execute --workspace-root U-UDP002

prepare 会自动把 04_TEMP 顶层的旧内容移动到：

U-UDP002\04_TEMP\A-Archive\U22B19A_PREPARE_时间戳

它只保留本次 3 个文件和 A-Archive，不删除 01_PROGRAMS、02_CONFIG、03_CASES 或 07_OUTPUT。

五、成功结果

Self-test 示例：

U22B19A-SELFTEST-PASS-18-R8-F29-C0

最终只需回传 execute 的一行：

B19A_NM1-Q1-D8-V4-W4-X0-C0

含义：

- NM1：安装 1 个新 Module 版本；
- Q1：formal qualification 与 audit 通过；
- D8：8 行 v0.3/v0.4 差分回放一致；
- V4：安装版本为 v0.4；
- W4：新增 4 个 Width 证据字段；
- X0/C0：无阻断错误。

六、输出位置

C-CODE\U-UDP002\07_OUTPUT\U22B19A_S1_WIDTH_INTERFACE_INSTALL_V01

其中包括：

- b19a_installation_summary.json
- B19A_RETURN_CAPSULE.txt

正式 Module 位于：

C-CODE\U-UDP002\01_PROGRAMS\modules\S1\CameraRadar.S1.CameraTargetContinuityArbitration\0.4.0

七、失败时

若出现 C7，只回传完整 B19AE 一行，不要让实现工具修改 Module、qualification controller 或旧 v0.3.0。
