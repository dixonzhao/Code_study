U3M7：Interactive Module Action Interface
公司电脑执行指南（CMD）

目标
----
把“工程师主动点击执行的工具”接入U003统一Module体系。
本节点只冻结公共接口，并安装一个小型参考Action；截图脱敏U3M8和Excel图表U3M9随后以独立Module加入。

下载后放置
----------
请把以下3个文件直接放入：
C-CODE\U-UDP003\04_TEMP

1. UDP003_U3M7_ACTION_INTERFACE_v0_1.zip
2. u003_u3m7_action_interface_installer_v0_1.py.txt
3. U3M7_START_HERE_CN_v0_1_2026-08-27.txt

执行位置
--------
打开CMD，进入C-CODE根目录。仅执行下面3行。

1. Prepare、清理旧U3M7临时项、校验哈希并安装：
python U-UDP003\04_TEMP\u003_u3m7_action_interface_installer_v0_1.py.txt --prepare --root U-UDP003 --package U-UDP003\04_TEMP\UDP003_U3M7_ACTION_INTERFACE_v0_1.zip

2. 独立验收已安装的接口、参考Action及真实artifact：
python U-UDP003\01_PROGRAMS\u003_u3m7_action_interface_acceptance_gate_v0_1.py --package-root U-UDP003

3. 启动U003：
python U-UDP003\01_PROGRAMS\u003_evidence_review_workbench_v0_19.py

界面确认
--------
1. 打开Modules，选择“Sample Artifact Action v0.1.0”并Add / Replace。
2. 主界面的“Module Actions (1)”应可点击。
3. 打开视频并完成FrameCount Mapping后，在Module Actions窗口选择“Write Context Summary”。
4. 点击Run Selected Action，应显示SUCCESS和Trace位置。
5. 输出目录中应出现u003_context_<Event>_<FrameCount>.json。

需要回传
--------
只需回传第2步最后一行，例如：
U3M7G N-R0.2-E0.3-P0.2-C0.3-G0.6-W0.19-T42-X0 C-0

如果第1步失败，回传U3M7PE整行；如果第2步失败，回传U3M7GE整行。

本节点明确不做
------------
- 不生成脱敏截图；该业务能力属于U3M8。
- 不生成Excel图表；该业务能力属于U3M9。
- 不改变ReviewResult、EngineerReviewMemo、Event边界或U002证据。
