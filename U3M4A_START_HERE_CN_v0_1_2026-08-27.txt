U003 / U3M4A Session语言锁与Algorithm Card执行指南
日期：2026-08-27

本步骤做什么
------------
U3M4A在U003启动时先显示English / 日本語选择窗口。选择后，本次Session的
主Review窗口、同步CAN窗口、Module Manager、Algorithm Card、文件对话框、
状态与错误提示统一使用该语言；进入主界面后不能再切换。

Algorithm Card不再默认显示一整块JSON，而是按照以下页签显示：

  Overview / 概要
  Method / Rules / 手法・ルール
  Interface / 入出力
  Validation / 検証
  Limits / 制約

Raw JSON只保留在最后一个只读高级页签。CSV列名、JSON Key、ModuleId、
Return Capsule、文件名和工程数据不会被翻译，因此不会破坏机器接口。

Prepare阶段
-----------
Prepare验证U3M4的4个关键前置文件、6个新payload及SHA-256；自动把U3M4旧
中转文件和PREPARED移动到A-Archive；重复执行时也会归档上一次U3M4A。

下载位置
--------
把以下三个文件下载到 C-CODE\U-UDP003\04_TEMP，ZIP无需解压：

  UDP003_U3M4A_SESSION_LOCALIZATION_v0_1.zip
  u003_u3m4a_session_localization_installer_v0_1.py.txt
  U3M4A_START_HERE_CN_v0_1_2026-08-27.txt

执行
----
使用CMD进入C-CODE根目录，只执行以下三行：

  python U-UDP003\04_TEMP\u003_u3m4a_session_localization_installer_v0_1.py.txt --prepare
  python U-UDP003\01_PROGRAMS\u003_u3m4a_localization_acceptance_gate_v0_1.py --self-test
  python U-UDP003\01_PROGRAMS\u003_u3m4a_localization_acceptance_gate_v0_1.py --accept --open-gui

人工确认
--------
第3行会先弹出语言选择。此次请选择“日本語”，然后确认：

  1. 主窗口、CAN窗口和Module Manager为日文；
  2. 进入主界面后不存在语言切换按钮；
  3. Module Manager显示2个Module family；
  4. Algorithm Card以5个结构化页签显示；
  5. Raw JSON只在最后一个只读页签；
  6. 关闭U003后终端输出G1和C-0。

回传
----
只回传最后一行：

  U3M4A N-L2-G1-I18-J10-K9-A6-R67-E9-T119-X0 C-0

失败时回传完整U3M4APE或U3M4AE错误行。
