U001 H6B3｜Selection Profile 编译与 H2 Preflight
版本：v1.0｜日期：2026-08-28

本节点目标
--------
将 H6B2 生成的 22-signal 暂定 Profile 编译成 H2 可执行请求，并使用真实 CANDump/DBC 进行 Preflight。仍然不解码 payload 数据行。

执行生命周期已恢复为统一标准：
prepare → self-test → execute

prepare 会做什么
----------------
- 清理或归档 H6B0/H6B1/H6B2 已被替代的传输脚本和 Start Here；
- 保留 U1H6B0_OUTPUT、U1H6B1_OUTPUT、U1H6B2_OUTPUT 作为上游证据；
- 归档旧的 U1H6B3_OUTPUT，防止误读旧结果；
- 逐项显示所检查文件、是否存在以及检查理由；
- 生成与当前程序版本绑定的 Prepare Receipt。

self-test 会做什么
-----------------
- 验证 Selection Compiler；
- 验证 H2 Adapter 的 DBC、byte decode、streaming 和输出契约；
- 验证 B2 Profile 仍是 PROVISIONAL 且没有解码 payload；
- 每组测试都会在 CMD 中用英文说明现实目的。

execute 会做什么
---------------
- 编译 22-signal Profile；
- 生成受控 H2 Request；
- 对真实 CANDump/DBC 执行 H2 Preflight；
- 确认 FrameCount 和信号数量一致；
- 不运行耗时的全量 decode。

文件放置
--------
把下面文件下载到：
C-CODE\U-UDP001\04_TEMP

u001_h6b3_profile_compile_preflight_v1_0.py.txt

CMD（从 C-CODE 根目录运行，仅三条）
------------------------------------
python U-UDP001\04_TEMP\u001_h6b3_profile_compile_preflight_v1_0.py.txt --prepare
python U-UDP001\04_TEMP\u001_h6b3_profile_compile_preflight_v1_0.py.txt --self-test
python U-UDP001\04_TEMP\u001_h6b3_profile_compile_preflight_v1_0.py.txt --execute

回传
----
prepare 和 self-test 若为 C0 不必回传。
只回传 execute 最后一行，例如：

U1H6B3-R003-C22-U22-F1-P1-A1-X0-C0

字段：
R = 暂定 Legacy Candidate 编号
C = 编译后的有效信号数
U = H2 受控请求中的信号数
F = FrameCount 配置检查
P = H2 Preflight READY
A = Legacy 身份歧义仍保持开放
