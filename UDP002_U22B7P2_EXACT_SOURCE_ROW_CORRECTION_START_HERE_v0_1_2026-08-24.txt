UDP002 U22B7P2 Exact Source Row Correction
版本：0.1
日期：2026-08-24

一、已确认的失败形状

返回：

B7PE K-NORECOVERABLE_G8_FAILURE-JG8-X1 C-7
MEMO1-FAILURE_1

表示 G8 只完成 G1，随后 G2 失败；它尚未运行到 G7，因此不能使用 G7
recovery。

B7P v0.1 按 U001 Interface Manual 使用 MaxSourceRows=0 表示 Full Source。
但真实 legacy G2 runtime 不接受 0。这里属于文档语义与真实实现不一致，
不是 CAN、DBC、Profile 或 geometry 算法失败。

二、v0.2 修正

v0.2 会自动：

1. 读取旧 V01 失败目录中的 Config、Stage manifest 和 G2 log；
2. 确认旧配置确实为 MaxSourceRows=0 且只有 G1 成功；
3. 用 16 MB block 流式统计 CANDump.csv 的精确数据行数；
4. 不读取或保存 Raw CAN 单元格内容；
5. 把精确正整数作为 MaxSourceRows 传给 G2；
6. 使用全新 V02 输出目录从头运行；
7. 如最终仅旧 G7 失败，再自动使用批准的 G7 v0.5 recovery；
8. 独立验证 Full Case、C22、V21 和四个 geometry identity。

三、下载与放置

从 public repo 下载两个文件到：

C-CODE\U-UDP002\04_TEMP

1. 本指南；
2. u002_u22b7p_full_geometry_materialization_controller_v0_2.py.txt

04_TEMP 中必须继续保留上次 ZIP 解压出的四个文件，尤其是：

- u002_u22b7p_full_geometry_materialization_controller_v0_1.py.txt
- u001_u22b1b14_isolated_profile_smoke_runner_v0_1.py.txt
- u001_output_package_assembler_v0_4.py.txt
- u001_output_package_assembler_v0_5.py.txt

不要删除旧 V01 失败输出目录，v0.2 会将其作为只读故障证据。

四、Self-test

从 C-CODE 根目录使用 CMD：

python U-UDP002\04_TEMP\u002_u22b7p_full_geometry_materialization_controller_v0_2.py.txt --self-test

最后预期：

UDP002-U22B7P2-SELFTEST-PASS-20 C-0

前面出现依赖程序 PASS 属于正常现象。成功时不用回传 Self-test。

五、正式修正运行

确认 V02 输出目录尚不存在，然后从 C-CODE 执行一整行：

python U-UDP002\04_TEMP\u002_u22b7p_full_geometry_materialization_controller_v0_2.py.txt --run-corrected-full --c-code-root . --prior-failure-root U-UDP001\03_CASES\TC001_20260422\02_RUNS\U22B7P_FULL_GEOMETRY_V01 --output-root U-UDP001\03_CASES\TC001_20260422\02_RUNS\U22B7P_FULL_GEOMETRY_V02

程序先统计 Raw CSV 行数，然后开始 Full CAN decode。运行时间可能较长。
不要关闭 CMD、不要移动文件、不要并行启动相同 Run。

六、输出目录确认

运行结束后：

dir U-UDP001\03_CASES\TC001_20260422\02_RUNS\U22B7P_FULL_GEOMETRY_V02

成功时应有：

- U22B7P2_COMPLETE.marker
- u22b7p2_full_materialization_manifest.json
- u22b7p2_return_capsule.txt

七、回传

回传两行即可：

B7P2 N-S...-U...-F...-C22-V21-G4-R...-H1-X0 C-0
B7P2I FIX-ZERO_TO_EXACT_POSITIVE_ROW_LIMIT-FULL_GEOMETRY_READY-NEXT_LINK_U002 C-0

失败时回传 B7P2E 与 MEMO1 两行。详细证据已经保存在 V02 输出目录。
