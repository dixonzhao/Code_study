UDP001 PK03H1R5 - Rebuild as one-folder portable runtime (Windows CMD)
Date: 2026-07-27

CONFIRMED PROBLEM
The previous onefile package attempted to extract unnecessary pandas test files into
the PyInstaller _MEI temporary folder and failed during application startup.

The package used both:
- --onefile
- --collect-all pandas

This combination is unnecessarily large and fragile for G8A, which repeatedly starts
child processes through sys.executable. The error does not prove antivirus involvement;
the packaging design must be corrected regardless.

APPROVED ARCHITECTURE
Use PyInstaller onedir:

U001_Workbench.exe
+ adjacent _internal runtime folder
+ nine external accepted U001 programs

The user still double-clicks one EXE. The complete release folder must stay together.
No project venv is required at runtime.

CHANGES IN BUILDER v0.6
- --onedir replaces --onefile;
- --collect-all pandas is removed;
- pandas.tests and numpy.tests are explicitly excluded;
- tkinter hidden imports remain included;
- runtime folder file count and total bytes are added to the manifest.

UNCHANGED
- u001_portable_runtime_host_v0_4.py
- all nine accepted U001 programs
- Data Contract
- algorithms
- GUI and orchestrator interfaces

DOWNLOAD THESE TWO FILES
1. u001_portable_host_package_builder_v0_6.py.txt
2. This instruction file

STEP 1 - COPY AND RENAME
Put the Builder file in UDP001\04_TEMP and remove only the final .txt suffix:

u001_portable_host_package_builder_v0_6.py

Reuse the existing:
UDP001\04_TEMP\u001_portable_runtime_host_v0_4.py

STEP 2 - ARCHIVE THE FAILED ONEFILE RELEASE
From the C-CODE root in Windows CMD:

move .\UDP001\05_PORTABLE_RELEASE .\UDP001\ARCH\PK03H1R4_ONEFILE_EXTRACTION_FAILURE_20260727

If the source folder does not exist, continue. If the destination already exists,
stop and use a new suffix rather than overwriting anything.

STEP 3 - BUILDER SELF-TEST
Use the existing activated venv:

python .\UDP001\04_TEMP\u001_portable_host_package_builder_v0_6.py --self-test

Expected:
U001-PORTABLE-HOST-PACKAGE-BUILDER-V06-SELFTEST-PASS-30

STEP 4 - BUILD ONEDIR RELEASE
python .\UDP001\04_TEMP\u001_portable_host_package_builder_v0_6.py --build --udp001-root .\UDP001 --preflight-report .\UDP001\03_CASES\TC001_20260422\03_RETURN\PK01_PREFLIGHT_01\u001_packaging_preflight_report.json --host-source .\UDP001\04_TEMP\u001_portable_runtime_host_v0_4.py --out .\UDP001\05_PORTABLE_RELEASE

Expected:
U001PK03H1
N-R1-D1-P9-H1-B1-E1-S9-Z1-M1-X0
C-0

STEP 5 - CHECK RELEASE LAYOUT
The following must exist together:

UDP001\05_PORTABLE_RELEASE\U001_Portable_v0_1\UDP001\00_LAUNCHER\U001_Workbench.exe
UDP001\05_PORTABLE_RELEASE\U001_Portable_v0_1\UDP001\00_LAUNCHER\_internal

Do not move the EXE away from _internal.

STEP 6 - REAL GUI SMOKE
Open U001_Workbench.exe from the path above.

Confirm:
- GUI opens without _MEI extraction;
- no tkinter import error appears;
- window remains responsive.

STEP 7 - GUI G8A SELF-TEST
Use the GUI Self Test action.

Expected in the GUI log:
UDP001-G8A2V05-SELFTEST-PASS-16

RETURN
