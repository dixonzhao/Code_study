U001 High-Code Workbench GUI U1G1 v0.2
=================================

目的
----
本次是启动可见性修正版。Windows语言选择窗口改为独立可见主窗口，安装器会确认GUI进程启动后至少持续存活2秒；若提前退出，会把原因写入04_TEMP的U1G1_GUI_LAUNCH_v0_2.log。

界面参考U002流水线设计，将U001显示为固定的I0-I5流程：

I0 Source Adapter
I1 Catalog & Mapping
I2 Decode & Canonical Mapping
I3 Frame Reconstruction
I4 Cadence & Bounded Hold
I5 Accepted Package & Quality Gate

其中，I0输入Adapter为模块化入口。当前可使用CAN dump CSV + DBC1 + DBC2；以后GNSS、LiDAR或其他数据源可以通过新增Adapter接入，而不改变U001核心契约。

U1G1的定位
------------
本次先完成可展示、可配置、可保存Profile的薄GUI：

1. 启动时选择EN或JA，本次会话中语言固定。
2. 自动发现Adapter并按版本归类。
3. 选择CAN dump、DBC1、DBC2。
4. 打开原有Catalog / Mapping子窗口，搜索并选择解码信号。
5. 设置Frame范围、输出目录及U002位置。
6. 显示I0-I5流水线及各阶段职责。
7. 保存Setup并检查Ready状态。

正式I0-I5自动执行属于下一小节U1G2。在Controller尚未安装时，Run I0-I5会明确Fail-close，不会伪装执行成功。

文件放置
--------
请把以下三个文件放入：

C-CODE\U-UDP001\04_TEMP

- UDP001_U1G1_HIGH_CODE_WORKBENCH_GUI_v0_2.zip
- u001_u1g1_workbench_gui_installer_v0_2.py.txt
- U1G1_START_HERE_CN_v0_2_2026-08-28.txt

执行位置
--------
使用CMD，先进入C-CODE目录。只执行下面三行：

python U-UDP001\04_TEMP\u001_u1g1_workbench_gui_installer_v0_2.py.txt --prepare
python U-UDP001\04_TEMP\u001_u1g1_workbench_gui_installer_v0_2.py.txt --self-test
python U-UDP001\04_TEMP\u001_u1g1_workbench_gui_installer_v0_2.py.txt --execute

三步含义
--------
prepare：确认U-UDP001、Adapter目录、旧Catalog GUI与传输包均存在，并解压检查内容和SHA-256。

self-test：在临时目录运行Model和GUI的无界面测试，并确认至少发现一个Adapter Card。

execute：安装两份高代码GUI程序，再次自测，然后自动启动U001 Workbench。

验收重点
--------
1. 启动时出现EN / JA选择。
2. 主界面横向显示I0-I5流水线。
3. Adapter family与Version可选且可刷新。
4. U002 link显示OFFLINE或ONLINE。
5. Catalog / Mapping按钮能够启动旧的信号选择窗口。
6. Check readiness能够区分未准备、准备完成和Controller缺失。
7. Run I0-I5在U1G2未安装前应给出说明，不得误报成功。

成功回传
--------
U1G1-N2-A?-G1-X0-C0

其中A表示被归档替换的旧GUI文件数量；第一次安装通常为A0。

如界面能够打开，请随后直接描述视觉和交互问题，不需要返回Self-test内容。
