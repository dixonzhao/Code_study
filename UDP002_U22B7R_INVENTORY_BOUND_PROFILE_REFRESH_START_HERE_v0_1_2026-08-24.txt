UDP002 U22B7R：按本次 S0 Inventory 重新生成 Binding Profile
版本：v0.1
日期：2026-08-24

一、这一步修什么

B7Q 已经成功完成 S0，但 Camera S1 拒绝了旧 Binding Profile：

PROFILE_INVENTORY_HASH

这是正确的 fail-close 行为。旧 Profile 绑定的是旧 U001 Signal Inventory；
B7P2 生成了新的 C22 / V21 全几何 U001 包，因此必须从本次 S0 实际输出的
u001_signal_inventory.csv 重新生成 Profile。禁止删除或绕过 Hash 检查。

二、运行前必须存在的三个文件

请确认以下三个文件直接位于：

U-UDP002\04_TEMP

1. u002_u22b7r_inventory_bound_profile_refresh_v0_1.py.txt
2. u002_u22b7q_full_geometry_relink_and_profile_v0_1.py.txt
3. u002_u22b7a_camera_lateral_evidence_profiler_v0_2.py.txt

在 C-CODE 的 CMD 中执行检查：

dir /b U-UDP002\04_TEMP\u002_u22b7r_inventory_bound_profile_refresh_v0_1.py.txt
dir /b U-UDP002\04_TEMP\u002_u22b7q_full_geometry_relink_and_profile_v0_1.py.txt
dir /b U-UDP002\04_TEMP\u002_u22b7a_camera_lateral_evidence_profiler_v0_2.py.txt

三、Self-test

从 C-CODE 根目录执行：

python U-UDP002\04_TEMP\u002_u22b7r_inventory_bound_profile_refresh_v0_1.py.txt --self-test

必须看到：

UDP002-U22B7R-SELFTEST-PASS-24 C-0

四、正式执行

仍从 C-CODE 根目录执行：

python U-UDP002\04_TEMP\u002_u22b7r_inventory_bound_profile_refresh_v0_1.py.txt --execute

程序将自动完成：

1. 验证 B7P2 六文件全几何 U001 包；
2. 只读读取失败 B7Q Run 中已经成功生成的 S0 Artifact；
3. 对该 S0 的 u001_signal_inventory.csv 计算 SHA-256；
4. 唯一绑定 7 个角色：CAM1/3 Distance、CAM1/3 LateralPosition、
   Radar Distance、Radar DetectionFlag、VehicleSpeed；
5. 在 02_CONFIG\signal_profiles 创建新的不可变 Profile；
6. 创建全新 B7R Run Configuration，不修改 B7Q 失败记录；
7. 重新执行 S0 → Camera S1；
8. 审核两个 Artifact；
9. 自动调用 B7A，输出横向几何证据统计。

五、输出位置

Return Capsule：

U-UDP002\04_TEMP\U22B7R_OUTPUT\u22b7r_return_capsule.txt

查看命令：

type U-UDP002\04_TEMP\U22B7R_OUTPUT\u22b7r_return_capsule.txt

U-UDP002\02_CONFIG\signal_profiles\tc001_camera_radar_full_geometry_binding_<inventory-hash>_v0_1.json

新 Run Configuration：

新 Run：

U-UDP002\07_OUTPUT\U22B7R_GEOMETRY_RELINK_F41380_41780_V01

六、成功标准与回传

成功时回传两行，格式类似：

B7R N-I22-B7-M2-A2-F401-G...-R0-P0-X0 C-0
B7A N-F401-G...-I...-D...-S8-X0 C-0

请原样回传这两行。

失败时回传：

B7RE K-...-J...-X1 C-7
MEMO1-...

同时保留：

U-UDP002\04_TEMP\U22B7R_OUTPUT\u22b7r_failure_diagnostic.json

七、禁止事项

- 不得修改旧 Binding Profile 的 SourceInventorySha256；
- 不得关闭 PROFILE_INVENTORY_HASH 检查；
- 不得覆盖 B7Q 失败 Run；
- 不得人工猜测重复或缺失的 Signal Role；
- 如任一角色不是唯一命中，保持 C-7 并回传诊断。
