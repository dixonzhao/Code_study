U001 H5 独立验收——公司电脑执行指南
版本：v1.1（2026-08-28）

目标
----
把已经独立验收的H3、H4A、H4B组装为U002可以直接读取的六文件可信数据包D1-D6，并使用独立Validator再次检查。

本轮Review View固定选择六个Golden Run信号：
- Camera 0x221 Distance
- Camera 0x221 LateralPosition
- Camera 0x251 Distance
- Camera 0x251 LateralPosition
- Radar 0x380 DistanceToObject
- Radar 0x380 PrecedingVehicleDetectionFlag

H5不重新解码、不补值、不改变测量值，也不执行Camera目标融合；它只负责原子封装、元数据连接、窄表生成和独立验收。

放置位置
--------
把下面两个文件放到：
C-CODE\U-UDP001\04_TEMP

文件：
u001_h5_direct_acceptance_v1_1.py.txt
u001_h5_package_assembler_v1_1.py.txt

v1.1修正
--------
Windows安全软件或索引服务可能短暂占用已经完成搬运的临时目录。v1.1仍保持六文件原子组装，但不再把“空暂存目录未能立即删除”误判为数据包失败。

输入位置
--------
C-CODE\U-UDP001\04_TEMP\U1H3D_OUTPUT\h3_output
C-CODE\U-UDP001\04_TEMP\U1H4D_OUTPUT
C-CODE\U-UDP001\04_TEMP\U1H4BD_OUTPUT

输出位置
--------
C-CODE\U-UDP001\04_TEMP\U1H5D_OUTPUT_V11\u001_final_package

v1.1使用新的输出目录，因此不会再次触碰上一次被Windows占用的旧U1H5D_OUTPUT。

执行方法
--------
在CMD中进入C-CODE根目录，只执行以下三行：

python U-UDP001\04_TEMP\u001_h5_direct_acceptance_v1_1.py.txt --prepare
python U-UDP001\04_TEMP\u001_h5_direct_acceptance_v1_1.py.txt --self-test
python U-UDP001\04_TEMP\u001_h5_direct_acceptance_v1_1.py.txt --execute

三步含义
--------
1. prepare：清理本阶段旧输出，逐项检查H3/H4A/H4B、策略包、Assembler和Validator。
2. self-test：验证六文件原子组装和独立验收的固定规则。
3. execute：解析六个Review信号，组装D1-D6，随后由独立Validator检查数量、Schema、Hash、来源链及D6是否为D2的精确子集。

通过标准
--------
只回传最终以 H5- 开头、以 -X0-C0 结尾的一行。

失败处理
--------
只回传以 H5E- 开头、以 -X1-C7 结尾的一行，不要修改已通过验收的H2-H4B产物。
