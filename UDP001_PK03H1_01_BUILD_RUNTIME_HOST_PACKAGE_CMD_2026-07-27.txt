Status: REPLACEMENT FOR THE ABANDONED COPIED-VENV RUNTIME ROUTE

1. ARCHITECTURE DECISION

The previous PK03 copied-runtime route is abandoned.

Reason:

- U001 was developed in a venv;
- the active pandas import uses a non-standard nested site-packages path;
- manually separating Base Python and venv site-packages did not preserve the
  original import environment;
- repeated copied-runtime patches would increase deployment risk.

PK03H1 instead builds one PyInstaller Runtime Host EXE containing:

- Python runtime;
- tkinter;
- pandas and its detected dependencies;
- an execution host for the nine accepted external U001 Python programs.

The accepted programs remain separate, SHA-256-verified files. The Runtime
Host executes them when GUI/G8 uses sys.executable. No Data Contract, Gate
algorithm, GUI workflow, or output schema is changed.
