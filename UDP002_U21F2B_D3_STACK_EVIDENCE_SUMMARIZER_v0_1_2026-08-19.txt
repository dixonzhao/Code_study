1. PURPOSE

Parse the already retained U21F2B timing diagnostic stack logs and inspect the
frozen Executor AST to identify the exact repeated project call site and wait
class. Do not execute, import, edit or copy the Executor.

Give a fresh Copilot chat only this instruction. It generates one downloadable

3. GENERATE EXACTLY ONE FILE

  u002_u21f2b_stack_evidence_summarizer_v0_1.py.txt

Use Python standard library only. Put it directly in U-UDP002\04_TEMP. Do not
generate BAT, PowerShell, corrected Executor, replacement evidence or report.


4. READ-ONLY BEHAVIOR

The summarizer must:

- require the Executor and diagnostic directory as explicit CLI paths;
- reject symlinks and missing/non-regular inputs;
- hash the Executor before and after parsing and require equality;
- parse every `stack_*.log` already present, without creating stack logs;
- parse the Executor with `ast.parse()` but never import/run it;
- refuse to write inside the diagnostic directory;
- write no project artifact other than its terminal capsule;
- redact absolute paths and never print source lines or hashes.


5. STACK PARSING

For each stack-log file:

1. split all faulthandler dumps;
2. extract normalized frames: basename, line number and function;
3. identify standard-library wait class:
   SUBPROCESS_WAIT, SLEEP_WAIT, IO_WAIT, LOCK_WAIT or OTHER;
4. select the nearest project-code caller above that wait;
5. group identical `(basename, line, function, wait_class)` locations;
6. record process count, total dumps, wait-classified dumps and unique project
   call sites.

Do not accept the previous D1 MEMO classification; rebuild from raw logs.


6. STATIC AST RESOLUTION

For each grouped Executor location, use the frozen AST to resolve:

- enclosing function;
- statement kind;
- direct call target names on that statement;
- whether the statement constructs or waits for a subprocess;
- whether a child command contains `--self-test`, `--module-worker`,
  `--dependency-preflight` or none;
- whether the same statement is inside a loop and the statically visible loop
  bound when it is a literal/range/list length.

Do not infer runtime values not present in logs/AST. Use UNKNOWN when unresolved.

`--self-test` uses private synthetic stack text and source text only. It proves
exactly 14 checks covering multi-PID/multi-dump parsing, five wait classes,
nearest project caller selection, AST call resolution, CLI-mode detection,
loop detection, path redaction, source immutability and stable capsule format.
