2. PRODUCT POSITION
======================================================================

GUI v0.4 is a human control client.  Controller v0.2 remains the sole public
AUTO_DISCOVERY control plane.

The GUI may:

- collect and validate human input;
- build explicit controller CLI argument lists;
- launch the controller through sys.executable, shell=False;
- display stage/status/log information;
- lock unsafe buttons while work is active;
- open an accepted output folder;
- validate an existing response;
- retain the accepted New Case workspace and legacy controlled-profile page.

The GUI must not:

- call G1, G10A2 or G10B1 directly;
- decode CAN;
- parse DBC;
- implement artifact-validation logic already owned by Controller v0.2;
- calculate validity, hold, FrameCount assignment, baseline, residual,
  correlation, anomaly or U002 statistics;
- repair/delete/reuse an existing request, preflight, Run or incomplete folder;
- choose a `latest` output by timestamp;
- silently change the RunId;
- create a false success when controller validation fails.

7. AUTO_DISCOVERY ACTIONS
======================================================================

Required buttons/actions:

1. Controller Self-test
2. Create Request
3. Preflight
4. Run Request
5. Validate Response
6. Execute New Run (1-5 sequentially after confirmation)
7. Validate Existing Response
8. Cancel
9. Open Response Folder

Button rules:

- only one worker/process may be active;
- Run Request is locked until request and preflight pass in the current GUI
  session;
- Execute New Run requires request, preflight, final and incomplete paths all
  absent before it starts;
- Validate Existing Response never requires the GUI to have created the Run;
  it calls only controller --validate-response against the selected/derived
  exact response folder;
- no action deletes an existing path;
- cancellation warns that incomplete evidence remains unaccepted;
- success is recognized only from process exit 0 plus exact controller token.

Exact accepted tokens:

- U001-G10C1R-SELFTEST-PASS-40
- G10C1-REQUEST-CREATED C-0
- G10C1-PREFLIGHT-PASS C-0
- G10C1-RUN-PASS C-0
- G10C1-VALIDATE-PASS C-0

9. AUTO_DISCOVERY SESSION CAPSULE
======================================================================

The GUI may write one small local session capsule only after an action finishes,
under:

It contains no source values and no absolute path.  Format:

U001GUI4
N-T<t>-Q<q>-P<p>-R<r>-V<v>-X<x>
C-<0_or_1>

where T=self-test, Q=request, P=preflight, R=run and V=response validation.
For Validate Existing Response, T/Q/P/R may remain zero and V may be one.

The GUI capsule is human-session evidence only.  It must never modify or
replace the Controller response manifest/capsule.
