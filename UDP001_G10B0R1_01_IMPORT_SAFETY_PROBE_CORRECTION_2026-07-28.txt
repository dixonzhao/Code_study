3. SINGLE APPROVED CHANGE
======================================================================

Replace the module import-safety child check with the exact semantic method
below.  Preserve all other v0.1 AST, configuration, topology, frame-shard,
manifest and capsule logic.

For each inspected module, launch an isolated child Python process that:

1. receives the absolute resolved ProgramRoot and ProgramPath;
2. sets cwd to a new empty temporary directory;
3. removes inherited PYTHONPATH from the child environment;
4. explicitly inserts only the resolved ProgramRoot at sys.path index 0;
5. creates a unique non-`__main__` module name;
6. uses importlib.util.spec_from_file_location;
7. uses importlib.util.module_from_spec;
8. inserts that module object into sys.modules under the unique name before
   exec_module, so dataclass/type resolution is valid;
9. calls spec.loader.exec_module(module);
10. prints IMPORT_OK and exits 0 only when import completes;
11. never calls module.main(), argparse, self-test or any CLI mode;
12. uses a finite timeout;
13. captures a categorized exception without storing absolute paths.

Running:

python accepted_program.py

with no arguments is a CLI execution test, not an import-safety test, and is
forbidden here.

The temporary cwd is intentional.  Sibling imports are allowed only through
the one explicit ProgramRoot entry.  Do not add C-CODE, Downloads, TEMP or any
other broad path.
