3. PROTOCOL POSITION

U21E has already authorized exact software, signal bindings, configuration and
FrameCount scope for one future Run. U21F2A defines the small JSON boundary used
between the future parent Executor and one child Module process:

  parent Executor -> validated Execution Request -> child Module
  child Module -> validated Execution Result -> parent Executor

It defines transport structure only. It contains no Camera/Radar mathematics,
baseline, residual, anomaly, SysID or U003 logic.


4. PROTOCOL BUNDLE ROOT

Create one deterministic JSON Schema 2020-12 document. Root keys are exactly:

  $schema
  $id
  title
  type
  $defs

Root type is object. `$defs` contains exactly:

  U002_MODULE_EXECUTION_REQUEST_V02
  U002_MODULE_EXECUTION_RESULT_V02

The bundle must use only this approved schema-keyword subset:

  $schema, $id, title, description, type, const, enum, required,
  additionalProperties, properties, items, minItems, maxItems,
  minLength, maxLength, minimum, maximum, pattern, anyOf, $defs, $ref

The validator must fail closed if the bundle contains any unsupported schema
keyword. Do not use `default`, `format`, `oneOf`, `allOf`, `if`, `then`, `else`
or implementation-specific extensions.

Every defined object must set `additionalProperties` to false. Unknown fields
must be rejected recursively, not only at the top level.


5. EXECUTION REQUEST v0.2

Required top-level fields, in the following logical order:

  ContractType
  ContractVersion
  RunId
  CaseId
  Stage
  ModuleIdentity
  Scope
  ClockDomain
  BoundSignals
  InputArtifacts
  Configuration
  ExecutionPolicy
  RuntimePaths

Constants:

  ContractType     = U002_MODULE_EXECUTION_REQUEST
  ContractVersion  = 0.2
  Stage            = S0, S1, S2, S3, S4, S5, S6 or S7

5.1 ModuleIdentity

Required exact fields:

  ModuleId
  ModuleVersion
  ManifestSha256
  ImplementationSha256
  Callable

SHA-256 values are 64 lowercase hexadecimal characters. Identifiers and
Callable are bounded non-empty strings. No absolute path is allowed here.

5.2 Scope

Required fields:

  Mode
  StartFrameCount
  EndFrameCount

Mode is FULL_CASE or FRAME_RANGE. Start/End use integer-or-null schema. Semantic
rules enforced by the validator:

- FULL_CASE requires both values null;
- FRAME_RANGE requires both integers and StartFrameCount <= EndFrameCount;
- bool must never be accepted as an integer.

5.3 ClockDomain

Required fields:

  ClockType
  PrimaryKey
  RateHz

For v0.2 ClockType is FRAMECOUNT and PrimaryKey is FrameCount. RateHz is a
finite positive number. This records the authorized clock; it does not infer or
repair timestamps.

5.4 BoundSignals

An array of zero or more strict binding objects. Each object requires:

  PortName
  Role
  Required
  SelectionMode
  CanonicalNames
  D3SemanticProjection
  D2Columns

Required is boolean. CanonicalNames and D2Columns are bounded arrays of unique,
non-empty strings. D3SemanticProjection is a strict JSON object containing only
JSON scalar values or bounded scalar arrays. The child may use only these exact
bindings; the future Executor must never search for replacements.

5.5 InputArtifacts

An array of zero or more strict objects requiring:

  ArtifactId
  ArtifactType
  ArtifactSchemaId
  ArtifactSchemaVersion
  ManifestSha256
  Payloads

Payloads is an array of strict objects requiring RelativePath, Role and
MediaType. RelativePath must be a normalized relative path: no absolute path,
drive prefix, `..`, empty segment or backslash. Runtime path resolution belongs
to the parent Executor, not to this logical identity.

5.6 Configuration

A JSON object supplied by accepted U21E evidence. It may contain nested JSON
objects/arrays/scalars, but the validator must recursively reject NaN, Infinity,
non-string mapping keys and values that are not JSON types. Do not impose
algorithm fields in the runtime protocol.

5.7 ExecutionPolicy

Required fields:

  FailurePolicy
  RequiredModule
  TimeoutSeconds
  MaxRetainedLogBytes

FailurePolicy is ABORT_RUN, BLOCK_DEPENDENT_PATH or SKIP_OPTIONAL_PATH.
RequiredModule is boolean. TimeoutSeconds is integer 1..86400.
MaxRetainedLogBytes is integer 1024..16777216. Semantic rule:
SKIP_OPTIONAL_PATH is invalid when RequiredModule is true.

5.8 RuntimePaths

Required fields:

  ModuleFile
  StagingRoot
  U001PackageRoot

These are bounded non-empty strings and may be absolute company-local paths.
RuntimePaths is explicitly ephemeral. The future Executor must delete the
request after the Module transaction and must never copy RuntimePaths into a
formal Run, Artifact, export or diagnostic Manifest.


6. EXECUTION RESULT v0.2

Required top-level fields, in logical order:

  ContractType
  ContractVersion
  RunId
  Stage
  ModuleId
  ModuleVersion
  Status
  Artifacts
  Warnings
  Metrics

Constants:

  ContractType     = U002_MODULE_EXECUTION_RESULT
  ContractVersion  = 0.2
  Stage            = S0..S7
  Status           = SUCCEEDED, SKIPPED or FAILED

6.1 Artifacts

Each strict Artifact declaration requires:

  ArtifactType
  ArtifactSchemaId
  ArtifactSchemaVersion
  Payloads
  CoordinateFrame
  UncertaintyReference
  Metadata

Each strict Payload declaration requires:

  RelativePath
  Role
  MediaType
  RowCount
  PayloadKind

RelativePath uses the same safe normalized-relative-path rule. RowCount is a
non-negative integer-or-null and never bool. PayloadKind is PRIMARY, AUXILIARY
or DIAGNOSTIC.

The Module must not report PayloadSha256, ByteSize, absolute locations or an
Artifact Manifest. The future parent Executor measures exact persisted bytes,
constructs the Artifact Manifest and owns final commitment.

Semantic rules:

- SUCCEEDED requires at least one Artifact;
- each successful Artifact requires at least one PRIMARY Payload;
- SKIPPED and FAILED require an empty Artifacts array;
- duplicate Payload RelativePath values are rejected.

6.2 Warnings, Metrics and Metadata

Warnings is a bounded array of short strings. Metrics and Artifact Metadata are
strictly bounded JSON mappings whose values may be JSON scalars or short scalar
arrays only. Nested objects, raw CAN rows, complete signal series, absolute
paths and binary/text payload contents are prohibited.

CoordinateFrame and UncertaintyReference are nullable bounded strings. Null
means explicitly unspecified; it does not mean that a frame or uncertainty was
verified.

  --self-test --protocol-bundle PATH

  --validate-result FILE --protocol-bundle PATH

Requirements:

- reject NaN and Infinity during parse, not after silent conversion;
- reject bool where integer/number is required;
- implement only the approved schema subset and reject unsupported keywords;
- resolve local `#/$defs/...` references only;
- enforce recursive additionalProperties false;
- perform the semantic rules listed in Sections 5 and 6;
- validate without modifying the bundle or input document;
- use bounded error text with no input values or absolute paths;
- print exactly one final stable capsule line;
- return process exit 0 for accepted validation and 7 for controlled denial;
- an uncontrolled internal exception returns 9 and a bounded stable capsule;
- use atomic temporary files only inside private self-test directories;
