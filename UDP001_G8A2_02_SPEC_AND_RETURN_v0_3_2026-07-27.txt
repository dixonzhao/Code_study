UDP001 G8A2 v0.3 — TECHNICAL SPECIFICATION AND RETURN PROTOCOL
Date: 2026-07-27

v0.3 portability correction:

- T01 writes exact LF bytes instead of using platform text translation;
- T02 checks exact atomic-output bytes;
- no runtime orchestration, data, interface, alias, or acceptance rule changed.

======================================================================
1. PURPOSE
======================================================================

G8A2 is a clean-room, thin control-plane orchestrator rebuilt from the frozen
Data Contract and accepted Gate CLI specifications.

It sequences Gate 1–Gate 7 but owns no data transformation or validation
algorithm.

======================================================================
2. CHANGES FROM THE ARCHIVED LINE
======================================================================

Removed:

- old G8A source inheritance;
- fixed smoke row counts as a PASS requirement;
- Gate 7 config or SourceId mutation;
- Reference/Candidate comparison;
- manifest normalization;
- G8B/G8R validation logic;
- any hidden field completion or data correction.

Added:

- fixed privacy-safe aliases CANDump.csv / DBC1.dbc / DBC2.dbc;
- fixed case path TC001_2026_0422/00_SOURCE-READONLY;
- config fingerprint;
- full SHA-256 freeze of modules, controls, Raw CAN, and both DBCs;
- independent --preflight mode;
- stop-on-first-failure;
- nine explicit subprocess stages;
- local logs and orchestration manifest;
- synthetic full-pipeline self-test.

======================================================================
3. PRIVACY AND PROVENANCE
======================================================================

The original sensitive source/DBC basenames are not needed by G8A2 and must
not be entered into any return capsule or external report.

The company may retain a company-local alias mapping if required for internal
provenance. G8A2 records the aliased basenames, sizes, modification times, and
SHA-256 values. Renaming does not change file content or SHA-256.

The original video is not read or hashed by G8A2.

======================================================================
4. FIXED EXECUTION ORDER
======================================================================

S1  Gate 1 probe
S2  Gate 2 selected decode
S3  Gate 3 FrameCount assignment
S4  Gate 4 semantic/validity classification
S5  Gate 5 Frame View
S6  Gate 6 cadence profile
S7  Gate 6 hold apply
S8  Gate 7 make-config
S9  Gate 7 build

G8A2 uses sys.executable, argument lists, and shell=False. Dependent stages are
sequential and never parallelized.

======================================================================
5. BOUNDARIES
======================================================================

G8A2 may:

- discover exact active filenames;
- read small control CSVs;
- derive the one approved FRAME_KEY CanonicalName;
- copy controls into the Run folder with hash equality;
- execute module self-tests and Gate CLIs;
- record stdout/stderr, return codes, capsules, file hashes, and row counts;
- stop and preserve failure evidence.

G8A2 must not:

- decode or modify data itself;
- sort, fill, infer, classify, aggregate, hold, fuse, or analyze values;
- edit Gate 7 local config;
- decide camera/radar association;
- call Radar ground truth;
- validate numerical equivalence between packages;
- overwrite or resume an existing run.

======================================================================
6. SELF-TEST ACCEPTANCE
======================================================================

The program contains exactly 16 deterministic self-tests. The final test
creates seven synthetic Gate programs, executes all nine subprocess stages,
builds one synthetic six-file package, and verifies a C-0 return.

Required:

UDP001-G8A2-SELFTEST-PASS-16

======================================================================
7. PREFLIGHT RETURN
======================================================================

File:

udp001_g8a2_preflight_capsule.txt

Format:

UDP001G8A2P1
N-Mm-Cc-Ii-Xx
C-n

Definitions:

M = exact active Gate modules, expected 7
C = exact control files, expected 4
I = protected external inputs, expected 3
X = blocking preflight errors

PASS:

M7 C4 I3 X0 C-0

Preflight executes no data Gate.

======================================================================
8. RUN RETURN
======================================================================

File:

CONTROL_OUTPUT/udp001_g8a2_return_capsule.txt

Format:

UDP001G8A2R1
N-Ss-Pp-Uu-Rr-Ff-Ii-Xx
S1-Cc S2-Cc S3-Cc S4-Cc S5-Cc S6-Cc S7-Cc S8-Cc S9-Cc
C-n

Definitions:

S = completed subprocess stages, expected 9
P = passed module self-tests, expected 7
U = final decoded Update rows
R = final Frame View rows
F = final package files, expected 6
I = protected module/control/input SHA-256 equality, expected 1
X = blocking orchestration errors, expected 0

G8A2 does not require fixed U/R values. Their values are runtime evidence.

PASS requires:

- S9;
- P7;
- all S1–S9 C0;
- F6;
- I1;
- X0;
- final C-0.

======================================================================
9. FAILURE PROTOCOL
======================================================================

On any failure:

1. do not modify code through Copilot;
2. do not rerun into the same output folder;
3. preserve config, output folder, manifest, logs, and capsule;
4. return the capsule plus at most three short Memo lines;
5. correct only from the exact failed StageId and evidence.

END
