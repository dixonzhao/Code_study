U3M9D XLSX视觉修补 v0.2.1
公司电脑执行指南

目的

本节点修复：Windows路径超过259字符、默认误选机器字段、图例位置、
FrameCount轴标签、Peak横线、Y轴名称/单位及Source Data表格样式。

v0.2.1同时修复v0.2第34项自测依赖操作系统临时目录长度的问题。
该修复不改变XLSX算法，只让路径压缩边界测试在Windows和macOS保持一致。

重要说明

1. 将本次3个文件直接放入：
   C-CODE\U-UDP003\04_TEMP

2. PREPARE会先验证本次ZIP、安装器和本说明文件，然后把04_TEMP内其余
   旧START_HERE、旧ZIP、旧安装器、旧PREPARED文件夹及散落文件全部移动到
   U-UDP003\A-Archive的时间戳目录。不会静默删除。

3. 请从C-CODE目录使用CMD运行以下三行；不要自行解压ZIP。

python U-UDP003\04_TEMP\u003_u3m9d_xlsx_visual_repair_installer_v0_2_1.py.txt --prepare
python U-UDP003\04_TEMP\u003_u3m9d_xlsx_visual_repair_installer_v0_2_1.py.txt --self-test
python U-UDP003\04_TEMP\u003_u3m9d_xlsx_visual_repair_installer_v0_2_1.py.txt --execute

成功后

1. 正常启动U003。
2. 在Module Manager中选择：
   Editable XLSX Chart Export v0.2.1
3. 进入Module Actions并打开该Action。
4. 不主动添加字段，确认默认Series不含：
   ActiveCandidateIds
   IsCandidatePeak
5. 设置Y-axis label与Physical unit，例如Distance和m。
6. 导出至少包含两张图的XLSX。
7. 确认：
   - 文件能从公司输出目录正常打开；
   - 每张图在独立Sheet，没有图表重叠；
   - Source Data使用Excel原生Table样式；
   - 图例在图上方；
   - X轴显示间隔化的整数FrameCount；
   - Peak是位于曲线上方的单个红点，不是一条0值折线；
   - Y轴显示“名称 (单位)”；
   - 数据与图表仍可在Excel内直接编辑。

请只回传视觉验收码：

U3M9DV-P1-T1-G1-X1-K1-Y1-D1-C0

字段：
P1 路径安全且能打开
T1 Source Data Table正常
G1 多图分Sheet且不重叠
X1 FrameCount刻度正常
K1 Peak红点正常
Y1 Y轴名称与单位正常
D1 默认不含两个机器字段
C0 无阻塞错误
