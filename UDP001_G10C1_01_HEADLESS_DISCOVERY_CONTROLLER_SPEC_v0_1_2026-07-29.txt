======================================================================
1. PROGRAM IDENTITY AND DESIGN PRINCIPLE
======================================================================

Filename:

u001_discovery_controller_v0_1.py

ProgramVersion:

0.1

Public responsibility:

- create a versioned U001 discovery request;
- validate the request and Case/program identities;
- execute accepted G1 -> G10A2 -> G10B1 child programs in order;
- stop on the first failure;
- publish one machine-readable response manifest only after every child gate
  and the final read-only validation pass;
- support exact-hash reuse without selecting files by timestamp or "latest".

The controller is control-plane code only.  It does not reimplement child
algorithms.

Import safety:

- importing performs no I/O, process launch, GUI action or logging;
- CLI execution exists only under if __name__ == "__main__";
- no global environment, cwd or pandas option is changed;
- every subprocess uses an explicit argument list, sys.executable,
  shell=False and an explicit cwd equal to UDP001\01_PROGRAMS;
- no command string is executed through a shell.

======================================================================
4. DISCOVERY REQUEST SCHEMA
======================================================================

Logical filename:

u001_discovery_request.json

Required JSON fields:

- RequestSchemaVersion = U001_DISCOVERY_REQUEST_V0_1
- RequestId
- DatasetId
- RunId
- SegmentId
- SourceId
- RequestedU001ContractVersion = U001_UNIFIED_DATA_CONTRACT_V0_1
- ProcessingMode = AUTO_DISCOVERY
- SignalScope = ALL_TECHNICALLY_ELIGIBLE
- FrameKeyChannel
- FrameKeyCANID, normalized uppercase 0x form
- FrameKeySignalName
- BatchSize
- ReusePolicy
- RequestedOutputRoot
- ExecutionPolicy object
- SourceFingerprintExpected object

ExecutionPolicy contains:

- ChunkSize
- MaxSourceRows, integer >=0, zero meaning full source;
- MaxAssignmentAgeRows;
- MaxRssMiB;
- UpdateBufferRows;
- FrameBufferRows;
- MemoryCheckEveryRows;
- MinimumFreeGiB.

SourceFingerprintExpected contains one record for each fixed alias:

- CANDump.csv;
- DBC1.dbc;
- DBC2.dbc.

Each record contains Basename, SizeBytes and SHA256.  --make-request computes
these values by streaming the physical files.  It never copies or modifies the
source.

RequestedOutputRoot rules:

- relative to CaseRoot;
- `/` is the canonical separator stored in JSON;
- must begin `02_RUNS/`;
- no drive, UNC path, empty component, `.` or `..` component;
- final component must equal RunId;
- generated request itself contains no absolute path.

Request JSON is deterministic: UTF-8, sorted keys, stable indentation, newline
termination, no wall-clock time, hostname, user name or absolute path.

RequestFingerprint is SHA-256 over canonical JSON excluding the
RequestFingerprint field and is stored in the request.

Request and output files are never overwritten.  --make-request requires an
absent output file.

======================================================================
5. PREFLIGHT
======================================================================

Preflight is read-only except for its explicit new output folder.

Checks:

1. exact request schema and vocabulary;
2. RequestFingerprint recomputation;
3. Case folder basename equals DatasetId;
4. the three fixed source aliases exist and are nonempty;
5. source size/hash exactly matches SourceFingerprintExpected;
6. all three accepted child programs exist by exact basename;
7. record child program SHA-256 values;
8. requested output resolves below CaseRoot and follows path rules;
9. batch/buffer/memory/row values are within specification;
10. free disk at output parent is at least MinimumFreeGiB;
11. FORCE_NEW_RUN requires final and temporary output roots to be absent;
12. REUSE_EXACT_HASH_ONLY may accept an existing final response only through
    the exact reuse rules in section 10;
13. run each child `--self-test` once and require process exit 0 plus these
    exact tokens in stdout:
    - UDP001-G1-SELFTEST-PASS-16
    - UDP001-G10A2-SELFTEST-PASS-20
    - the exact self-test token physically produced by accepted v0.5a,
      provided it matches
      `UDP001-G10B1<optional uppercase/digit revision>-SELFTEST-PASS-<positive integer>`.
      Record the exact accepted token.

The flexible numeric suffix for G10B1 is deliberate because v0.5a extended
tests during defect correction.  Exit 0 plus the strict token grammar are both
required; generic text containing PASS is insufficient.

Preflight output:

- u001_g10c1_preflight_manifest.json
- udp001_g10c1_preflight_capsule.txt

No absolute path is stored.  Store basenames, hashes, policy values, checks and
completion code.

Success terminal line:

G10C1-PREFLIGHT-PASS C-0

Failure:

G10C1-ERROR:PREFLIGHT:<CATEGORY> C-7

Construct the response manifest, then run the same read-only validation logic

9. DISCOVERY RESPONSE MANIFEST
======================================================================

Logical filename:

u001_discovery_response_manifest.json

Required identity:

- ResponseSchemaVersion = U001_DISCOVERY_RESPONSE_V0_1;
- RequestSchemaVersion;
- RequestId;
- RequestFingerprint;
- DatasetId;
- RunId;
- SegmentId;
- SourceId;
- U001ContractVersion;
- ProcessingMode;
- SignalScope;
- ProfileId;
- ReuseStatus = NEW_RUN or EXACT_HASH_REUSE;
- source/DBC hashes;
- child program basenames/hashes;
- FrameCount Channel/CAN ID/Signal name and observed range;
- catalog/eligible/excluded/candidate/batch counts;
- source/update/frame counts;
- quality-gate status;
- warning/error arrays;
- CompletionCode.

Artifact declarations:

- request;
- G1 catalog, summary and capsule;
- all eight G10A2 files;
- every G10B1 root file;
- every G10B1 update shard;
- every G10B1 frame shard;
- child logs, excluding the response manifest/capsule themselves.

Each declaration contains:

- Role;
- RelativePath using `/`;
- SizeBytes;
- SHA256;
- DataRowCount for CSV or blank for non-CSV;
- ColumnCount for CSV or blank for non-CSV.
- EvidenceSource = CONTROLLER_SCAN or G10B_CHILD_MANIFEST.

For request, G1, G10A2 and controller-log artifacts, hashing and CSV shape
counting are streaming/bounded-memory and EvidenceSource=CONTROLLER_SCAN.

For G10B1 root files and shards, copy relative path, SHA-256, row and column
evidence from the already validated u001_g10b_run_manifest.json and set
EvidenceSource=G10B_CHILD_MANIFEST.  Do not rescan 8-10 GB merely to construct
the parent response.  Response validation invokes the accepted G10B1 child
validator, then cross-checks every copied declaration against the child
manifest.  This preserves the evidence chain without a redundant third full
artifact scan.

Never load an entire shard.  Do not self-hash the response manifest or
completion capsule.

Manifest JSON is deterministic and contains no absolute path, wall-clock time,
host name, user name or modification time.

ReadyForU002 = 1 only when:

- child C1..C5 passed;
- response validation passed;
- all declared artifacts exist and hashes/counts match;
- CompletionCode=0;
- no blocking quality status exists.

======================================================================
10. EXACT-HASH REUSE
======================================================================

FORCE_NEW_RUN:

- block when requested final or temporary output exists;
- never overwrite or repair.

REUSE_EXACT_HASH_ONLY:

- allowed only when final output already exists and temporary output does not;
- run complete --validate-response logic;
- request fingerprint, source/DBC hashes, child program hashes, contract,
  frame-key identity, batch size and all ExecutionPolicy values must match;
- every declared artifact hash/count must match;
- CompletionCode=0 and ReadyForU002=1 required;
- no file is modified;
- return reuse success.

If any identity differs, return C-7.  Do not run into the existing folder and
do not select another folder automatically.

======================================================================
11. READ-ONLY RESPONSE VALIDATION
======================================================================

--validate-response must:

- read only the requested response root;
- require the exact top-level folder structure;
- recompute RequestFingerprint;
- verify Case source hashes against request and response;
- verify current accepted child hashes against response;
- invoke G10A2 --validate-output on 02_PROFILE_CONFIG;
- invoke G10B1 --validate-output on 03_DISCOVERY_DATA;
- stream-verify controller-owned request/G1/G10A2/log artifacts;
- invoke G10B1 validation to stream-verify G10B1 outputs once, then require
  every G10B response declaration to exactly match the validated G10B child
  manifest;
- verify all identities and counts agree across request, G1, G10A2, G10B1 and
  response;
- reject undeclared data artifacts except the response manifest/capsule;
- reject absolute paths or path traversal in manifest artifact records;
- require CompletionCode=0 and ReadyForU002=1;
- never repair, rewrite or normalize the response.

Success terminal line:

G10C1-VALIDATE-PASS C-0

Failure terminal line:

G10C1-ERROR:VALIDATE:<CATEGORY> C-7
