U3M8H1 — Signal CSV bisect 修复
中文三步执行说明

问题

旧版 U003 读取 RB001 Review Data CSV 时出现：

  Signal CSV error: name 'bisect' is not defined

这是 U003 GUI Shell 缺少标准库导入造成的代码缺陷，不是 RB001 数据错误。

准备

- 关闭正在运行的 U003。
- 将 ZIP 和安装程序放入 C-CODE\U-UDP003\04_TEMP。
- 从 C-CODE 目录使用 CMD 执行。

第1步：安装修复

python U-UDP003\04_TEMP\u003_u3m8h1_signal_csv_fix_installer_v0_1.py.txt --install --root U-UDP003 --package U-UDP003\04_TEMP\UDP003_U3M8H1_SIGNAL_CSV_FIX_v0_1.zip

成功码：
U3H1P N-F4-S1-W1-G1-X0 C-0

第2步：验收门

python U-UDP003\01_PROGRAMS\u003_u3m8h1_signal_csv_acceptance_gate_v0_1.py --root U-UDP003

成功码：
U3H1G N-S1-W1-B1-L1-T21-X0 C-0

第3步：启动并复测同一份 RB001 Review Data

python U-UDP003\01_PROGRAMS\u003_evidence_review_workbench_v0_21.py

确认：

1. 加载原来报错的 RB001 Review Data CSV。
2. 右侧同步 CAN 表能够显示并随 FrameCount 高亮滚动。
3. Plot CSV 导出仍可执行。
4. U3M8 Evidence Image Redaction 仍可打开。

只需回传：

U3H1V-SIGNAL1-SCROLL1-PLOT1-MASK1-C0

失败时将对应 1 改为 0，并补充一条短 Memo。
