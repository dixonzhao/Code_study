UDP003 A2 - VISIBLE GUI ACCEPTANCE
Date: 2026-07-31
Status: COMPANY EXECUTION READY

PURPOSE
Perform one short visible acceptance of the unchanged Reviewer v0.5 after A1.
Use one representative existing video window. Do not re-review all prior cases.

RUN FROM WINDOWS CMD AT C-CODE ROOT

python U-UDP003\01_PROGRAMS\framecount_video_reviewer_v0_5.py

CHECKLIST

G - GUI
  Main video window and synchronized CAN window both open normally.

V - Video / FrameCount
  Open the existing test video, enter the known mapping, and jump to one known
  FrameCount. The displayed video position matches the visible video overlay.

E - Event navigation
  Load one existing Event Queue CSV. Event selection and Start/End navigation
  move to the expected interval. Event loop can be enabled and stopped.

T - Synchronized CAN table
  Load one existing narrow Review Data CSV. FrameCount is first and every
  supplied comparison column is visible in the independent CAN window.

L - Lag
  Change the CAN highlight lag by one FrameCount and apply it. The yellow target
  row moves by one FrameCount in the expected direction; restore the original
  lag after checking.

P - Plot CSV
  Enter small non-negative Before/After ranges and export. Exactly one new CSV
  is created around the yellow row and retains every loaded Review Data column.

R - Review output
  Enter one review code and a short temporary memo, save, then export reviews.
  A full review-result CSV and compact return-code TXT are created.

S - Screenshot
  Save the displayed video frame. One PNG is created with FrameCount and video
  frame identifiers in its filename.

RETURN

If all checks pass, return only:
  UDP003A2 N-G1-V1-E1-T1-L1-P1-R1-S1-X0 C-0

If a check fails, use 0 for that item, set X to the number of failed items and
C-7. Add at most three short MEMO lines for failures that cannot be represented
by the capsule.

Do not modify the source during A2. A2 C-0 authorizes UDP003PK01 onedir
packaging and final UDP003 Node Report generation.
