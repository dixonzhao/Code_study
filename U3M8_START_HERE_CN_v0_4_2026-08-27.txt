U3M8 v0.4 — Live Evidence Redaction
中文三步执行说明

目的

解决 U3M8 打开后 U003 无法继续操作的问题，并允许：

- U3M8 窗口跟随 U003 当前 FrameCount / Event；
- 在 U003 中换位置后，使用同一个 U3M8 窗口继续截图；
- 一次 Action Session 连续导出多组原图＋マスキング图；
- Event 存在时发布 Start/Peak/End；没有 Event 时发布当前点前后各100行；
- 为后续制图 Module 提供 Peak 高亮与数据标签选项。

注意

1. 运行安装前关闭正在运行的 U003。
2. 三个下载文件放到：C-CODE\U-UDP003\04_TEMP
3. 命令均从 C-CODE 目录使用 CMD 执行。
4. 安装会把 U3M8 v0.3 和被替代的 U003 v0.19 源文件移入 A-Archive。
5. 安装后需要在 Module Plan 中选择 Evidence Image Redaction v0.4.0。

第1步：Prepare / Install

python U-UDP003\04_TEMP\u003_u3m8_live_redaction_installer_v0_4.py.txt --install --root U-UDP003 --package U-UDP003\04_TEMP\UDP003_U3M8_LIVE_EVIDENCE_REDACTION_v0_4.zip

成功码：
U3M8P N-F10-M1-A1-L1-R1-X0 C-0

第2步：Self-test / Acceptance Gate

python U-UDP003\01_PROGRAMS\u003_u3m8_live_redaction_acceptance_gate_v0_1.py --root U-UDP003

成功码：
U3M8G N-M1-A1-L1-S1-E1-R1-T41-X0 C-0

第3步：启动新版 U003

python U-UDP003\01_PROGRAMS\u003_evidence_review_workbench_v0_20.py

人工确认顺序

1. 选择 EN 或 JA，并正常加载 Video、Event CSV、Review Data CSV。
2. Module Plan 选择 CameraRadar.U003.FrameMask v0.4.0。
3. 打开 Module Actions，选择 Export Redacted Evidence。
4. U3M8 打开后，不要关闭它；返回 U003，切换 FrameCount 或下一个 Event。
5. 确认 U3M8 的图片、FC、Event、Range、Peak 自动更新。
6. 在第一个位置画好区域并 Export Evidence Pair。
7. 返回 U003 换到第二个位置，再次 Export Evidence Pair。
8. 关闭 U3M8，确认 Action 完成并记录 ExportCount / ExportRecords。
9. 取消 Follow U003 后，确认 U003 移动时 U3M8 保持当前画面。

请只回传：

U3M8V4-SYNC1-MULTI1-FREEZE1-PAIR1-C0

含义：

- SYNC1：U003 可操作且 U3M8 跟随 Frame/Event
- MULTI1：一个窗口连续导出至少两组
- FREEZE1：关闭 Follow U003 后画面冻结
- PAIR1：每组原图、マスキング图、Profile 都存在

如果失败：将对应 1 改为 0，并只补 1—3 条短 Memo。
