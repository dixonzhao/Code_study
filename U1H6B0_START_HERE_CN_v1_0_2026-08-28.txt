U001 H6B0｜正式差分复跑包只读盘点
版本：v1.0｜日期：2026-08-28

目标
----
自动查找 U-UDP001 内已有的标准 D1-D6 输出包，并区分：
1. Legacy 真实包；
2. High-Code H5 真实包；
3. Synthetic / Test 包；
4. 不完整或身份未知的包。

本步骤只读取文件，不修改、移动或删除任何已有包，也不计算全量 Hash。

文件放置
--------
把下面这个文件直接下载到：
C-CODE\U-UDP001\04_TEMP

u001_h6b0_package_inventory_v1_0.py.txt

请勿改名，也不需要删除 .txt 后缀。

CMD 执行（从 C-CODE 根目录运行）
--------------------------------
1. 自测：
python U-UDP001\04_TEMP\u001_h6b0_package_inventory_v1_0.py.txt --self-test

2. 执行只读盘点：
python U-UDP001\04_TEMP\u001_h6b0_package_inventory_v1_0.py.txt

输出位置
--------
C-CODE\U-UDP001\04_TEMP\U1H6B0_OUTPUT

生成：
- u001_h6b0_package_inventory.csv
- u001_h6b0_package_inventory.json
- u001_h6b0_capsule.txt

成功回传
--------
只需回传最后一行机器码，例如：
U1H6B0-N8-L1-H1-S4-I1-U1-E2-X0-C0

字段：
N = 找到的候选目录总数
L = Legacy 真实完整包数量
H = High-Code H5 真实完整包数量
S = Synthetic / Test 包数量
I = 不完整包数量
U = 身份未知包数量
E = 当前可进入正式复跑预检的包数量

如果 L=0 或 H=0，不要手动猜路径；下一步将根据 CSV 清单决定是定位旧包，还是用真实源文件生成新的 High-Code H5 包。

边界
----
- B0 不认定两个包可以比较；只建立包清单。
- B0 不运行 H6 差分比较。
- B0 不信任 TEMP、Archive、Test 或 Synthetic 路径为正式包。
- 正式 H6B1 会对选中的两个包重新做身份、范围和 Hash 预检。
