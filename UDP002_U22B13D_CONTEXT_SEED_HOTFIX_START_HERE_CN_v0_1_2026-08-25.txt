UDP002 U22B13D Context Seed Hotfix v0.1
========================================

目的
----
修复旧版已验收 B1B4 配置不包含 ContextFrameStart，导致 B13D 在组合全视频
运行计划时停止的问题。该修复不修改 Camera 重建算法、Radar 有效性规则、
S6 候选规则或 S7 导出规则。

文件放置
--------
将下载的：

u002_u22b13d_tc001_full_video_run_v0_2.py.txt

放入：

C-CODE\U-UDP002\04_TEMP

从 C-CODE 目录执行（共两条）
-------------------------------
python U-UDP002\04_TEMP\u002_u22b13d_tc001_full_video_run_v0_2.py.txt --self-test
python U-UDP002\04_TEMP\u002_u22b13d_tc001_full_video_run_v0_2.py.txt --execute --workspace-root U-UDP002 --frame-start 7400 --frame-end 57597

成功标准
--------
第一条：

第二条：

范围规则
--------
7400 和 57597 是本次 TC001 Run 的显式输入，不再是生产代码中的默认值。
以后更换分析范围时必须同时修改 --frame-start 与 --frame-end，并确保对应的
已验收 U001/U002 来源覆盖同一 FrameCount 范围。程序不会自行猜测范围。

失败时
------
停止执行，仅回传 B13DE 与 B13DD 两行。不要修改 Core、Module 或 Validator。
