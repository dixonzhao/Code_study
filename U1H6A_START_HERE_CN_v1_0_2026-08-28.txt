U001 H6A Legacy Differential Replay——执行指南

本节点只验收差异审计器，不读取公司原始CAN/DBC，也不执行正式Legacy对比。
它会自动寻找上一节点U1H5验收生成的run_a合成六文件包。

把以下三个文件放入 C-CODE\U-UDP001\04_TEMP：
1. UDP001_U1H6A_DIFFERENTIAL_REPLAY_HIGH_CODE_v1_0.zip
2. u001_u1h6a_differential_replay_installer_v1_0.py.txt
3. 本说明文件

在CMD中进入C-CODE根目录，运行三行：

python U-UDP001\04_TEMP\u001_u1h6a_differential_replay_installer_v1_0.py.txt --prepare
python U-UDP001\04_TEMP\u001_u1h6a_differential_replay_installer_v1_0.py.txt --self-test
python U-UDP001\04_TEMP\u001_u1h6a_differential_replay_installer_v1_0.py.txt --accept

成功后只回传第三行机器码，预期格式：
U1H6Q-T8-C6-X0-C0

T8：八项独立验收；C6：六种差异分类全部覆盖；X0/C0：成功。
失败时回传04_TEMP\U1H6A_DIAGNOSTIC.json中的ErrorType和Error。
