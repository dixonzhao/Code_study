U001 H6B5D7 全DBC FrameCount候选检查 - 执行说明
================================================

目的
----
自动读取当前受控请求中的DBC1和DBC2，搜索所有名称包含Frame+Count/Counter的信号，
再使用原始CSV逐一验证。无需人工猜测0x620属于哪个Channel。

程序使用与H2相同的DBC Parser和Byte Decoder，只读数据，不修改文件。
全量扫描期间每50000行显示一次进度。

放置位置
--------
将两个文件直接放入：
C-CODE\U-UDP001\04_TEMP

从C-CODE目录执行（仅三行）
----------------------------
python U-UDP001\04_TEMP\u001_h6b5d7_all_dbc_frame_candidate_diagnostic_v1_0.py.txt --prepare
python U-UDP001\04_TEMP\u001_h6b5d7_all_dbc_frame_candidate_diagnostic_v1_0.py.txt --self-test
python U-UDP001\04_TEMP\u001_h6b5d7_all_dbc_frame_candidate_diagnostic_v1_0.py.txt --execute

需要回传
--------
只回传execute最后一行：

H6B5D7-...

每个K字段依次表示：Channel.CAN_ID.有效行数.不同值数.最小值.最大值.下降次数。
详细Message/Signal名称保存在本地JSON，不需要手敲。

本结果将直接决定Frame同步修复方案。
