UDP002 U22B1 B15 — U001/U002 正式接口验收
版本：0.1
日期：2026-08-21

本步骤做什么
============

B14-R4 已经成功生成 22 信号、21 Frame View 信号的六文件 U001 Package。

B15 是 B1 的最后一道只读 Gate：

1. 验证 D1-D6 文件、Hash、行数和 schema；
2. 验证 ClockDomain/NativeTimestamp/MessageCounter 的最终补全规则；
3. 按 Channel + CAN ID + SignalName 精确绑定：
   - FrameCount；
   - Camera 1 Distance；
   - Camera 3 Distance；
   - Radar DistanceToObject；
   - Radar PrecedingVehicleDetectionFlag；
4. 验证这四个测量信号已进入 21-signal Frame View；
5. 导出只有五列的最小人工检查表。

B15 不运行 Camera reconstruction，不计算 discrepancy，不判断任何传感器错误，
也不修改 U001/U002。通过后 B1 正式封口，进入 B2 Radar validity。

需要下载
========

把下面一个文件放入：

C-CODE\U-UDP002\04_TEMP

文件：

u002_u22b1b15_u001_interface_acceptance_v0_1.py.txt

Step 1 — Self-test
==================

从 C-CODE 使用 CMD：

python U-UDP002\04_TEMP\u002_u22b1b15_u001_interface_acceptance_v0_1.py.txt --self-test

成功：

U22B1B15-SELFTEST-PASS-18

通过时不用回传 Self-test。

Step 2 — 确认 Package 路径
===========================

B14-R4 输出根目录内依次进入：

G7V05_BUILD\U001_PACKAGE

这个 U001_PACKAGE 目录中必须直接看到六个文件：

u001_decoded_updates.csv
u001_frame_values.csv
u001_signal_catalog.csv
u001_quality_report.csv
u001_run_manifest.json
u001_review_view.csv

如果目录实际叫 U001_PACKAGE_001 等，CMD 中使用你看到的真实名称。

按照前一版推荐路径，通常为：

U-UDP001\03_CASES\TC001_20260422\02_RUNS\U22B1B14_R4_G7V05_V01\G7V05_BUILD\U001_PACKAGE

Step 3 — 执行 B15
==================

若 Package 路径与上面一致，执行以下一整行：

python U-UDP002\04_TEMP\u002_u22b1b15_u001_interface_acceptance_v0_1.py.txt --accept --package "U-UDP001\03_CASES\TC001_20260422\02_RUNS\U22B1B14_R4_G7V05_V01\G7V05_BUILD\U001_PACKAGE" --out-root "U-UDP002\07_OUTPUT\U22B1B15_INTERFACE_V01"

若你的 B14-R4 目录名称不同，只修改 --package 后的路径。

out-root 必须是尚不存在的新目录。

输出
====

U-UDP002\07_OUTPUT\U22B1B15_INTERFACE_V01 中将只有：

1. u22b1b15_interface_acceptance_receipt.json
2. u22b1b15_minimal_subgraph.csv
3. u22b1b15_return_capsule.txt

最小 subgraph 只有五列：

FrameCount
Camera1Distance
Camera3Distance
RadarDistance
RadarDetectionFlag

成功时只回传 return capsule 两行：

B15 N-U...-F...-C22-V21-B5-H1-X0 C-0
B15I N-S01-S11-D10-D21-D31-D41-D51-D61-X0 C-0

失败时只回传终端最后两行 B15E / B15D；诊断已集成，不再额外跑 probe。
