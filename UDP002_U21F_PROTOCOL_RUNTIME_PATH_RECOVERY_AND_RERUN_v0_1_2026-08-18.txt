  U21FD3 E-RuntimeError CL-72 FN-selftest P-10011 C-0

  Engine, Protocol Bundle, Protocol Validator, Core Schema, Core Validator

Therefore:

- Engine exists and is a regular file;
- Protocol Bundle path is not a regular file;
- Protocol Validator path is not a regular file;
- frozen Core Schema exists and is a regular file;
- frozen Core Validator exists and is a regular file.

This is a runtime-path/naming defect before the formal self-test matrix. It is
not evidence of an Executor, Protocol ABI or Module-execution logic defect.
