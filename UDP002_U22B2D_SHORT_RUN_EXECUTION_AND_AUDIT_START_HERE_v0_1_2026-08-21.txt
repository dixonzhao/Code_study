UDP002 U22B2D — Frozen Short Run Execution + Artifact Audit
版本：0.1
日期：2026-08-21

本节点的作用
============

B2C 只冻结了执行计划，B2D 才第一次真正运行这五个 Module：

S0  U001可靠数据接入
S1  Camera目标连续性重建
S1  Radar测量有效性解释
S2  三分流比较总体
S3  有符号Camera–Radar discrepancy

运行区间固定为 FrameCount 41480–41750，不增加新算法，也不修改
Module、Data Contract或公式。

B2D完成后自动验收
=================

1. U22基础程序运行前后Hash状态一致；
2. Stage Executor完成5个Module且无Optional Failure；
3. Run状态为SUCCEEDED；
4. 五种Artifact各存在且只有一个；
5. Radar、Population、Outcome的FrameCount逐行一致；
6. Radar valid/invalid计数闭合；
7. Formal / Investigation / Ineligible三分流计数闭合；
8. OutcomeValidRows等于FormalEligibleRows；
9. 只有FORMAL_ELIGIBLE行计算discrepancy；
10. 每个有效值都满足：

    CameraRadarDiscrepancy = RadarDistance - CanonicalCameraDistance

失败时程序会自动生成结构化诊断文件，并额外输出一条B2DD机器码；不需要再运行独立Probe。

需要下载
========

把下面文件下载到：

C-CODE\U-UDP002\04_TEMP

u002_u22b2d_short_run_execution_and_audit_v0_1.py.txt

Step 1 — Self-test
==================

在 C-CODE 使用 CMD：

python U-UDP002\04_TEMP\u002_u22b2d_short_run_execution_and_audit_v0_1.py.txt --self-test

成功：

B2D-ST N-T26-X0 C-0

Self-test通过时不用回传。

Step 2 — 执行真实短Run并验收
=============================

python U-UDP002\04_TEMP\u002_u22b2d_short_run_execution_and_audit_v0_1.py.txt --execute-and-audit --workspace-root U-UDP002

运行区间只有约13.5秒，正常情况下不应像U001全量解析那样长时间运行。

成功时只回传B2D一行：

B2D N-M?-A?-R?-V?-L?-F?-I?-N?-O?-P?-X0 C-0

字段含义：

M  完成Module数，预期5
A  Artifact数，预期5
R  本区间Frame行数
V  Radar有效测量行数
L  Radar目标丢失证据行数
F  Formal Eligible行数
I  Investigation Only行数
N  Ineligible行数
O  有效discrepancy行数，应等于F
P  是否为完全相同Run的重放，首次通常0

失败时回传两行：

B2DE ... C-7
B2DD ... C-0

不要自行修改Run、Module或旧程序；诊断信息已由B2D程序保存。
