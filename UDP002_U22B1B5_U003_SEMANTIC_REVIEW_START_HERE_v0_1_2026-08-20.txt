一、目的

B1B4 已证明程序、配置、Artifact 和 lineage 正确，但还不能证明
CanonicalCameraDistance 在真实视频中选择了正确目标。B1B5 使用 U003 对
自动生成的6个窗口进行人工语义复核。

二、需要的两个文件

进入：

    U-UDP002\07_OUTPUT\U22B1B4_...\

选择含有以下 receipt 的 B1B4 Run 文件夹：

    u22b1b4_normalized_retry_run_receipt_v0_1.json

在该文件夹内使用：

1. Event CSV
   04_REVIEW_PACKAGE\u22b1b4_s1_semantic_review_queue.csv

2. Review Data CSV
   05_EXPORTS\u22b1b4_camera_reconstruction_plot_view.csv

Review Data 只有4列：

- FrameCount
- Camera1Distance
- Camera3Distance
- CanonicalCameraDistance

三、U003 操作

1. 启动 U003 Evidence Review Workbench。
2. 加载 TC001 对应的视频。
3. 加载上述 Event CSV。
4. 加载上述 Review Data CSV。
5. 使用已经验证过的 FrameCount mapping。
6. 逐个复核 SRV001 至 SRV006；播放前后片段，并观察黄色当前行。

六个窗口的关注点：

- SRV001 15120-15245：Camera1/3 同时丢失及重新捕捉
- SRV002 30488-30679：视频目标与 Camera1/3 对齐关系
- SRV003 37800-39000：Camera1/3 切换开始区间
- SRV004 41598-41638：两个 Camera 数据均无效
- SRV005 42199-42208：预期稳定选择
- SRV006 52592-53013：后半段连续性选择

四、每个窗口只选一个码

1 = 正确：Canonical 跟随视频中的同一目标，选择/连续性合理
2 = 错误：Canonical 明显选择错误 Camera 来源或错误目标
3 = 不适合评价：目标不可见、两个 Camera 均失效或场景本身不可评价
4 = 无法判断：疑似视频/CAN时差、信号定义或显示逻辑问题
5 = 视频不可用

Short Memo 仅在代码无法表达时填写1至3条短句。

五、最短回传

只需手动输入一行：

    B1B5 Q1-1 Q2-1 Q3-2 Q4-3 Q5-1 Q6-1 C-0

把示例数字替换为实际结果。不要手敲完整 CSV。

六、判断规则

- Q1/Q2/Q3/Q5/Q6 以 1 为主要通过条件。
- Q4 预期可能为 3；两个 Camera 同时无效时，Canonical 不应伪造有效值。
- 任一窗口为 2：保留 S1 为 PROVISIONAL，进入针对性算法修订实验。
- 只有技术验收与语义复核均通过，S1 才可进入本次 Golden Run 主线。
