UDP002 U22B12 失败 Run 只读诊断指南
版本：v0.1

目的：
一次性确定 U22B12 在第几个 Module、哪个 Stage、以什么内部理由退出。
本程序只读，不修改失败 Run、配置、Module 或 Artifact。

一、下载位置

把以下文件放到：

C-CODE\U-UDP002\04_TEMP

1. u002_u22b12_failed_run_diagnostic_v0_1.py.txt
2. UDP002_U22B12_FAILED_RUN_DIAGNOSTIC_START_HERE_v0_1_2026-08-24.txt

二、CMD 执行

从 C-CODE 根目录执行：

python U-UDP002\04_TEMP\u002_u22b12_failed_run_diagnostic_v0_1.py.txt --self-test

预期：B12DST PASS-12 C-0

然后执行：

python U-UDP002\04_TEMP\u002_u22b12_failed_run_diagnostic_v0_1.py.txt --diagnose --workspace-root U-UDP002

三、只回传两行

B12D1 ... C-0
B12D2 ... C-0

完整诊断文件会自动写入：

U-UDP002\04_TEMP\U22B12_DIAGNOSTIC_OUTPUT\u22b12_failed_run_diagnostic.json

字段：

C = 已完成 Module 数
Q = 失败 Sequence
S = Stage
M = Module 短名
RC = 子进程退出码
A = 已生成 Artifact 数
K = 从子进程 capsule、stdout、stderr、Module log 中提取出的最相关原因

不要删除、移动或修改当前失败 Run。取得两行后再发布针对该 Module 的一次性修正。
