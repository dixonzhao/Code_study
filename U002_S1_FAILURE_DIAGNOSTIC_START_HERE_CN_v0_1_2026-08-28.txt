U002 S1 最近失败诊断
====================

将以下文件放入：
C-CODE\U-UDP002\04_TEMP

- u002_latest_run_failure_diagnostic_v0_1.py.txt

关闭 U002 GUI 后，从 C-CODE 根目录运行一行 CMD：

python U-UDP002\04_TEMP\u002_latest_run_failure_diagnostic_v0_1.py.txt --workspace-root U-UDP002 --run-id GR_U001H5_20260828B

程序会直接显示：
- 失败的 S1 Module 名称和版本；
- Executor 失败原因；
- 子程序 stdout/stderr 最后一行；
- 完整诊断文件夹。

只需回传最后一行 `S1D-...-C0`。
如果实际 Run ID 不是 GR_U001H5_20260828B，请把命令末尾的 Run ID 改成 GUI 中使用的值。
