UDP002 U22B2F Context-Aware Golden Run 执行说明 v0.1
日期：2026-08-21

一、本节点做什么

B2E已经证明：B2DR3从FrameCount 41480直接启动Camera有状态重建，遗漏FrameCount 7400的人工Seed和中间历史，因此271帧全部处于歧义状态。

B2F只修正这一条边界：

- Context/Warmup范围：7400–41750，用于建立Camera内部状态；
- Evaluation范围：41480–41750，只允许这271帧输出给后续分析；
- Camera连续性、切换、有效性、Radar和discrepancy数学不变。


二、下载并放入04_TEMP的三个文件

u002_u22b2f_context_aware_camera_module_installer_v0_1.py.txt
u002_u22b2f_context_aware_plan_builder_v0_1.py.txt
u002_u22b2f_context_aware_run_and_audit_v0_1.py.txt

不要改文件名，不要删除.txt后缀。


三、在C-CODE目录检查文件

if not exist U-UDP002\04_TEMP\u002_u22b2f_context_aware_camera_module_installer_v0_1.py.txt echo MISSING-B2F-INSTALLER

if not exist U-UDP002\04_TEMP\u002_u22b2f_context_aware_plan_builder_v0_1.py.txt echo MISSING-B2F-PLANNER

if not exist U-UDP002\04_TEMP\u002_u22b2f_context_aware_run_and_audit_v0_1.py.txt echo MISSING-B2F-RUNNER

if not exist U-UDP002\07_OUTPUT\U22B2DR3_TC001_F41480_41750_V01\02_DIAGNOSTICS\b2e_formal_population_diagnostic_v0_1.json echo MISSING-B2E-EVIDENCE

四条命令都不应输出MISSING。


四、运行三个Self-test

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_camera_module_installer_v0_1.py.txt --self-test

成功：

U22B2FI-ST N-T10-F5-X0 C-0

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_plan_builder_v0_1.py.txt --self-test

成功：

UDP002-U22B2F-PLAN-SELFTEST-PASS-21 C-0

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_run_and_audit_v0_1.py.txt --self-test

成功：

UDP002-U22B2F-RUN-SELFTEST-PASS-30 C-0

任何Self-test出现C-7都立即停止，不继续执行。


五、安装Camera Module v0.2.0

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_camera_module_installer_v0_1.py.txt --install-module --workspace-root U-UDP002

成功格式：

U22B2FI N-F5-H1-R0-X0 C-0

如果Module已经以相同内容安装，R可能为1，也属于成功。


六、创建并Preflight新的B2F Run

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_plan_builder_v0_1.py.txt --build-plan --workspace-root U-UDP002

成功格式：

B2FP N-M5-Q数字-R数字-C7400-E41480.41750-X0 C-0

然后检查Run目录：

if not exist U-UDP002\07_OUTPUT\U22B2F_TC001_F41480_41750_V01\00_CONFIG\resolved_run_plan.json echo MISSING-B2F-PLAN

不应输出MISSING。


七、执行并验收五模块Run

python U-UDP002\04_TEMP\u002_u22b2f_context_aware_run_and_audit_v0_1.py.txt --execute-and-audit --workspace-root U-UDP002

Camera Module需要读取7400–41750的上下文，因此比271帧短Run慢，但不会把上下文行输出到正式Artifact。

成功格式：

B2F N-M5-A5-R271-CV数字-W数字-V数字-L数字-F数字-I数字-N数字-O数字-P数字-X0 C-0

验收要求：

- CV必须大于0；
- W必须大于0；
- F必须大于0；
- O必须等于F；
- R必须为271；
- 最后一项必须为C-0。


八、只需要回传

三个正式执行结果：

1. U22B2FI ... C-0
2. B2FP ... C-0
3. B2F ... C-0

Self-test全部正常时不用回传。

若出现C-7，只回传完整错误行；若程序同时生成B2FD诊断行，也一起回传。
