# Hit & Blow（C言語）

4桁の数字を当てるゲームです。
コンピューターは、0〜9から同じ数字がない答えを作ります。

## コンパイルと実行

すべてのソースファイルを一緒にコンパイルします。

```sh
gcc hitandblow.c hbsetting.c hbjudge.c -o hitandblow
./hitandblow
```

## ファイルの役割

- `hitandblow.c`: `main()`とゲーム全体の流れ
- `hbsetting.c`: `makeCorrect()`の処理
- `hbsetting.h`: `makeCorrect()`の宣言
- `hbjudge.c`: `checkCorrect()`の処理
- `hbjudge.h`: `checkCorrect()`の宣言

ヘッダーファイルには、ほかのファイルから使う関数の宣言だけを書きます。
`#ifndef`、`#define`、`#endif`は、同じヘッダーが二回読み込まれることを防ぎます。

## 遊び方

ゲームを始めると、次の文が出ます。

```text
Hit & Blowゲームを始めます。
4桁の数字を入力してください:
```

- Hit: 数字と場所が同じです。
- Blow: 数字はありますが、場所が違います。

例えば、答えが`1234`、入力が`1834`の場合は`3 Hit 0 Blow`です。
正解するまで入力を続けます。

数字以外の入力と、4桁ではない入力は使えません。

## プログラムの流れ

1. `srand()`と`time()`で乱数の準備をします。
2. `makeCorrect()`で、同じ数字がない答えを作ります。
3. プレイヤーの入力が4文字の数字か確認します。
4. `checkCorrect()`でHitとBlowを数えます。
5. 戻り値が`0`なら、もう一度入力します。
6. 戻り値が`1`なら、正解なので終了します。

## 関数の説明

### `main()`

ゲーム全体を進めます。
入力は最初に文字列として読みます。
これは、`0987`の先頭の`0`と、入力した文字数を確認するためです。
確認した後で`int`に変えて、`checkCorrect()`に渡します。

`checkCorrect()`の戻り値を`isCorrect`に入れます。
`isCorrect`が`0`の間は、`while`で入力を繰り返します。

### `int makeCorrect(void)`

`rand() % 10`で0〜9の数字を作ります。
新しい数字が前の数字と同じか、`for`と`if`で調べます。
同じではないときだけ配列に入れます。
最後に4個の数字を一つの`int`にして返します。

答えが`0987`の場合、`int`では`987`になります。
しかし、判定するときに必ず4桁に分けるため、先頭は`0`として扱うことができます。

### `int checkCorrect(int cor, int ans)`

`cor`は正解、`ans`はプレイヤーの入力です。
二つの数を4個ずつの数字に分けます。
同じ位置を調べてHitを数え、その後で違う位置のBlowを数えます。
一つの数字を二回数えないように、使った位置を配列に記録します。

正解の場合は正解メッセージを表示して`1`を返します。
不正解の場合はHitとBlowを表示して`0`を返します。
HitとBlowを戻り値に入れないので、`main()`の条件が分かりやすくなります。

## 今回変更した理由

- 前の関数名は`Checkcorrect`でした。名前の付け方が正しくなかったため、lowerCamelCaseの`checkCorrect`に直しました。
- 関数の仕事を分かりやすくするため、結果の表示と正解の判断を`checkCorrect()`にまとめました。
- 課題の指定に合わせて、正解なら`1`、不正解なら`0`を返す形にしました。
- 各機能を説明しやすくするため、ゲーム、答えの作成、判定を別のファイルに分けました。
- テストに対応するため、数字以外の入力と4桁ではない入力を確認する処理を追加しました。
- `0987`のような入力を確認できるように、入力時だけ文字列を使います。関数の引数は課題指定どおり`int`です。

## テストした内容

- 4 Hit 0 Blow
- 0 Hit 4 Blow
- HitとBlowが両方ある場合
- 0 Hit 0 Blow
- 数字以外の入力
- 4桁ではない入力
- 正解した後の終了
