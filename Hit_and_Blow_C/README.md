# Hit & Blow（C言語）

4桁の数字を当てるゲームです。
コンピューターは、0〜9から同じ数字がない答えを作ります。

## コンパイルと実行

```sh
cc hit_and_blow.c -o hit_and_blow
./hit_and_blow
```

## 遊び方

画面に次の文が出たら、4桁の数字を入力します。

```text
4桁の数字を入力してください:
```

- Hit: 数字と場所が同じです。
- Blow: 数字はありますが、場所が違います。

例えば、答えが `1234`、入力が `1834` の場合は `3 Hit 0 Blow` です。
4 Hitになるまで入力を続けます。

## プログラムの流れ

1. `srand()`と`time()`で乱数の準備をします。
2. `makeCorrect()`で、同じ数字がない答えを作ります。
3. プレイヤーから数字を入力します。
4. `Checkcorrect()`でHitとBlowを数えます。
5. 4 Hitでなければ、もう一度入力します。
6. 4 Hitなら、お祝いの文を出して終了します。

## 関数の説明

### `main()`

ゲーム全体を進めます。
答えを作り、入力を受け取り、結果を表示します。
`while (hit != 4)`なので、正解するまで繰り返します。

### `int makeCorrect(void)`

最初の数字は`rand() % 9 + 1`で1〜9から作ります。
二つ目からは`rand() % 10`で0〜9から作ります。
新しい数字が前の数字と同じか、`for`と`if`で調べます。
同じではないときだけ配列に入れます。
最後に4個の数字を一つの`int`にして返します。

### `int Checkcorrect(int cor, int ans)`

`cor`は正解、`ans`はプレイヤーの入力です。
最初に、二つの数を4個ずつの数字に分けます。

次に、同じ位置を調べてHitを数えます。
Hitではない場所だけをもう一度比べて、Blowを数えます。
一つの数字を二回数えないように、使った場所を配列に記録します。

この関数の戻り値は一つの`int`です。
そのため、`Hit × 10 + Blow`を返します。
例えば3 Hit 0 Blowなら`30`を返します。
`main()`で割り算と余りを使い、HitとBlowに戻します。
