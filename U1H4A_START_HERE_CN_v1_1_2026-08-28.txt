U001 H4A Raw Frame View 安装与验收

目标
----
把 H3 的长格式 Canonical Update Stream 转换为：
- 每个已观测 FrameCount 恰好一行；
- 保留同帧更新次数、源行范围、有效性和缺失原因；
- 不做跨帧 hold；
- 不补 0；
- 不合成缺失 FrameCount。

H4A 只完成原始 Frame View。Cadence 与 bounded hold 属于下一节点 H4B，
GUI/Workbench 属于 H7。

放置位置
--------
将以下三个文件直接放入：
C-CODE\U-UDP001\04_TEMP

- UDP001_U1H4A_RAW_FRAME_VIEW_HIGH_CODE_v1_1.zip
- u001_u1h4a_raw_frame_view_installer_v1_1.py.txt
- 本说明文件

执行环境
--------
打开 Windows CMD，当前位置必须是 C-CODE。

只执行以下三条命令
------------------
python U-UDP001\04_TEMP\u001_u1h4a_raw_frame_view_installer_v1_1.py.txt --prepare
python U-UDP001\04_TEMP\u001_u1h4a_raw_frame_view_installer_v1_1.py.txt --self-test
python U-UDP001\04_TEMP\u001_u1h4a_raw_frame_view_installer_v1_1.py.txt --execute

成功标志
--------
最终只需回传第三条命令最后一行：

U1H4A-N3-P1-Q1-H1-A7-X0-C0

字段含义
--------
N3 = 安装 3 个 H4A 程序文件
P1 = Frame Policy 编译器通过
Q1 = 独立 H3→H4A 验收通过
H1 = H3 兼容性保持
A7 = 安装 7 个受控 payload 文件
X0 = 无失败项
C0 = 完成

本节点安装和验收使用合成数据，不要求立即运行公司全量数据。
