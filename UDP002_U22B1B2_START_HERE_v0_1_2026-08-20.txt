UDP002 U22B1B2 执行说明（Windows CMD）
版本：v0.1
日期：2026-08-20

一、本节点做什么

本节点把已经批准的 Camera Target Reconstruction Algorithm Card 转换为受控的 S1 Module，并完成：

1. Module 安装；
2. Module self-test；
3. U22 Module Qualification；
4. B1B0 Signal Binding Profile 原字节提升；
5. TC001 Module Configuration 生成；
6. Foundation 前后不变验证。

本节点不处理完整实测数据。真正读取 U001 Accepted Package 并在短区间运行，是下一节点 U22B1B3。

二、把文件放在哪里

从 GitHub 下载以下三个文件，全部直接放到：

.\U-UDP002\04_TEMP

不要改文件名，不要让 Copilot 重写代码，也不要放进 04_TEMP\A-Archive。

三、执行前必须已经存在

1. .\U-UDP002\04_TEMP 中必须只存在一个：
   u22b1b0_signal_binding_proposal_*.json

2. 以下 U22 Foundation 文件必须仍在正式目录：
   .\U-UDP002\01_PROGRAMS\core\u002_u22_module_qualification_v0_1.py
   .\U-UDP002\05_TESTS\integration\u002_u22_synthetic_vertical_acceptance_v0_1.py

如果缺少这些文件，停止执行，不要临时修改 Gate。

四、从 C-CODE 根目录依次执行

Step 1：Installer self-test

python .\U-UDP002\04_TEMP\u002_u22b1b2_s1_camera_target_reconstruction_installer_v0_1.py.txt --self-test

成功输出：
U22B1B2I-ST N-T10-F5-X0 C-0

Step 2：Acceptance self-test

python .\U-UDP002\04_TEMP\udp002_u22b1b2_s1_camera_target_reconstruction_acceptance_v0_1.py.txt --self-test

成功输出：
U22B1B2-ST N-T15-X0 C-0

Step 3：正式安装与验收

python .\U-UDP002\04_TEMP\udp002_u22b1b2_s1_camera_target_reconstruction_acceptance_v0_1.py.txt --accept --workspace-root .\U-UDP002

成功输出：
U22B1B2 N-I1-Q1-P1-C1-F1-X0 C-0

五、成功后会生成或确认的正式资产

Module：
.\U-UDP002\01_PROGRAMS\modules\S1\CameraRadar.S1.CameraTargetContinuityArbitration\0.1.0

Promoted Binding Profile：
.\U-UDP002\02_CONFIG\binding_profiles\TC001_camera_radar_base_provisional_v0_1.json

Module Configuration：
.\U-UDP002\02_CONFIG\module_configs\u22b1b2_camera_target_reconstruction_tc001_v0_1.json

Acceptance Receipt：
.\U-UDP002\00_CONTROL\registry\u22b1b2_camera_target_reconstruction_acceptance_receipt_v0_1.json

六、Return Capsule 含义

I1 = Module 已安装
Q1 = Module Qualification 通过
P1 = B1B0 Profile 已按原字节提升
C1 = TC001 Configuration 已生成
F1 = U22 Foundation 前后保持不变
X0 / C-0 = 无错误，验收通过

七、只需要回传什么

两个 self-test 如果通过，不需要回传。

只回传 Step 3 最后一行：

U22B1B2 N-I1-Q1-P1-C1-F1-X0 C-0

如果出现 C-7，立即停止，只回传那一行错误，不要让 Copilot修改程序或 Gate。

八、工程意义

S1 的职责不是直接判断 Camera 或 Radar 谁错，而是把 Camera 1 / Camera 3 的多个候补目标信号，经有效性、连续性和 hysteresis 规则重建为一条带置信状态的 Canonical Camera Target。Radar 和 Recognition_ID 均不参与本模块的目标仲裁，避免把比较对象或不可靠选择信号反向泄漏进 Camera 重建过程。
