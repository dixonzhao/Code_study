UDP002 U22B1AF1 - D4 frame_view_signal_count Consumer 修正
版本：v0.1
日期：2026-08-20

一、已确认的问题

真实 U001→U002 验收返回：

U22B1AM N-F0-R0-K0-Q0-X1 C-7 R-D4_SIGNAL_COUNT

原因不是 U001 输出损坏，也不是 frozen Executor 失败。

U001 D3 Signal Catalog 可以包含全部 catalog signals；其中只有
IncludeInFrameView=1 的 signals 被物化到 D2 Frame View。

因此 U001 D4 的 frame_view_signal_count 正确定义为：

  count(D3 rows where IncludeInFrameView = true)

B1A Module 0.1.0 错误地把该值与 D3 catalog 总行数比较。Synthetic fixture
中所有 D3 signals 都进入 D2，所以该实现错误未被暴露；真实 package 中二者
不同，因此被正确地 fail-close。

二、修正原则

1. U001 Data Contract 不修改；
2. 真实 U001 六文件不修改；
3. frozen Phase A 不修改；
4. 保留 Module 0.1.0 作为历史证据；
5. 发布 Module 0.1.1，仅修正 consumer count semantics；
6. 0.1.1 self-test 明确包含“3个catalog signals、2个Frame View signals”的回归场景；
7. 使用 B1AR v0.2 重新运行真实衔接。
