UDP001 PK03H1R4 - Frozen tkinter submodule correction (Windows CMD)
Date: 2026-07-27

CONFIRMED CAUSE
The PK03H1 build passed all nine hosted --self-test programs, but real GUI creation
failed because PyInstaller analyzed the Runtime Host entry point and did not discover
the tkinter submodules imported only by the external runpy-loaded GUI.

Missing frozen modules:
- tkinter.filedialog
- tkinter.messagebox
- tkinter.ttk

This is a packaging dependency-declaration defect. Do not modify the accepted GUI,
the other eight U001 programs, Data Contract, algorithms, or program interfaces.

CORRECTION
- Runtime Host v0.4 explicitly imports the three tkinter submodules.
- Builder v0.5 also declares the three PyInstaller hidden imports.
- Runtime Host self-test verifies the required GUI APIs.
