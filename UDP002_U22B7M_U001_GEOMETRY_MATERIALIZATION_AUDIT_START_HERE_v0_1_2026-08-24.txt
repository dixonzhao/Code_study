UDP002 U22B7M 执行指南
U001 Geometry Materialization Audit
版本：0.1
日期：2026-08-24

一、目的

一次性确认：

1. U-UDP002 中是否存在真正包含 Camera 1/3 Distance + LateralPosition
   的 U001 实体包；
2. 该实体包是否在 A-Archive 外；
3. 现有七个 S1 Run 分别引用了哪个 U001 包；
4. 包存在但链接错误，还是包根本没有生成。

程序只读取目录、Catalog、Frame View 表头和 module_request.json。
它不读取 Raw CAN 数据行，不修改任何包，也不执行 Decoder。

二、文件放置

下载后直接放入：

C-CODE\U-UDP002\04_TEMP

三、自测

从 C-CODE 根目录使用 CMD：

python U-UDP002\04_TEMP\u002_u22b7m_u001_geometry_materialization_audit_v0_1.py.txt --self-test

预期：

UDP002-U22B7M-SELFTEST-PASS-16 C-0

四、正式运行

python U-UDP002\04_TEMP\u002_u22b7m_u001_geometry_materialization_audit_v0_1.py.txt --workspace-root U-UDP002 --output-dir U-UDP002\04_TEMP\U22B7M_OUTPUT

五、输出确认

dir U-UDP002\04_TEMP\U22B7M_OUTPUT

输出：

1. b7m_u001_package_inventory.csv
2. b7m_s1_run_input_linkage.csv
3. b7m_materialization_audit_quality.json
4. b7m_return_capsule.txt

六、回传

只回传一行 B7M capsule：

B7M N-P...-G...-A...-R...-RG...-S7...-D...-X0 C-0

D0：已有 geometry 包被 S1 引用，继续查解析器。
D1：geometry 包存在，但 Run 引用了其他包；下一步修链接并重跑。
D2：没有 geometry 实体包；下一步从已通过的22信号 Profile 重跑 U001。

END OF GUIDE
