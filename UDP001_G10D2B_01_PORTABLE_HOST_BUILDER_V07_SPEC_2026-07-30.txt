UDP001 G10D2B — Portable Host Package Builder v0.7 Implementation Specification
Date: 2026-07-30
Status: IMPLEMENTATION CANDIDATE SPECIFICATION; DO NOT PROMOTE; DO NOT BUILD PACKAGE YET

0. Purpose

Upgrade the accepted historical builder
    u001_portable_host_package_builder_v0_6.py
to
    u001_portable_host_package_builder_v0_7.py

The new builder packages the accepted U001 architecture after G10A-G10C:

    12 formal Python programs
    4 control CSV files
    Portable Runtime Host v0.5
    PyInstaller onedir runtime

G10D2B is only the builder implementation and independent conformance gate.
Do not run a real PyInstaller build in this node. Do not promote any candidate.

1. Copilot input files — exactly three

Attach these three files to a fresh Copilot chat:

1) accepted historical source:
   u001_portable_host_package_builder_v0_6.py

2) accepted G10D2A candidate runtime host:
   u001_portable_runtime_host_v0_5.py

3) this specification:
   UDP001_G10D2B_01_PORTABLE_HOST_BUILDER_V07_SPEC_2026-07-30.txt

The v0.6 builder is the implementation baseline. Preserve working PyInstaller,
atomic-write, hashing, evidence and hosted-self-test mechanisms unless this
specification explicitly replaces them.

2. Required Copilot output

Return exactly one downloadable text file:

    u001_portable_host_package_builder_v0_7.py.txt

The file content must be valid Python source. Do not return only a chat code
block. Do not add “download”, spaces, Japanese text, or another suffix to the
filename. The user removes only the final .txt before execution.

3. Fixed identity

The generated source must define:

    PROGRAM_NAME = "u001_portable_host_package_builder_v0_7.py"
    PROGRAM_VERSION = "0.7"
    SELFTEST_TOKEN = "U001-PORTABLE-HOST-PACKAGE-BUILDER-V07-SELFTEST-PASS-40"
    PACKAGE_NAME = "U001_Portable_v0_2"
    MANIFEST_SCHEMA = "UDP001_PORTABLE_HOST_PACKAGE_V0_2"
    EXPECTED_DEPENDENCIES = ["pandas"]

The program must be import-safe and must not launch a build or GUI on import.

EXPECTED_PROGRAMS must be an ordered tuple containing exactly these 12 files:

1. u001_foundation_core_v0_1.py
2. u001_selected_update_decoder_v0_1.py
3. u001_framecount_assignment_v0_1.py
4. u001_semantic_validity_classifier_v0_1.py

The legacy GUI file u001_data_preparation_workbench_gui_v0_3.py is an allowed
development-root fallback only. It must not be copied into the release and must
not appear in EXPECTED_PROGRAMS, the manifest program list or package capsule.

5. Exact control inventory

EXPECTED_CONTROLS must be an ordered tuple containing exactly:

1. u001_g2_selected_signals.csv
2. u001_g4_signal_policy.csv
3. u001_g5_frame_policy.csv
4. u001_g6_hold_policy.csv

All four are copied byte-for-byte from UDP001\02_CONTROL to the portable
UDP001\02_CONTROL folder. Record Bytes and SHA256 for each. A missing control is
a blocking error. Do not infer, regenerate or modify a control file.

6. Runtime Host v0.5 contract

The builder must require the supplied host source to satisfy all of the
following before PyInstaller is invoked:

- PROGRAM_VERSION == "0.5"
- DEFAULT_GUI_NAME == "u001_data_preparation_workbench_gui_v0_4a.py"
- approved program inventory equals EXPECTED_PROGRAMS exactly
- source self-test returns zero and stdout contains:
  U001-PORTABLE-HOST-V05-SELFTEST-PASS-24

Do not retain the v0.4 host token. Do not depend on the removed v0.4-only
--probe protocol. Hosted program tests must use the v0.5 direct-script dispatch:

    U001_Workbench.exe <absolute-program-path> --self-test

Return code zero and a PASS token in captured stdout are required for every
formal program.

7. Builder API contract

Provide these import-safe functions:

    get_portable_builder_contract() -> dict
    build_release_plan(udp001_root: Path,
                       host_source: Path,
                       out: Path) -> dict
    pyinstaller_host_command(host_source: Path,
                             dist: Path,
                             work: Path,
                             spec: Path) -> list[str]
    run_self_test() -> None
    run_build(udp001_root: Path,
              host_source: Path,
              out: Path) -> int
    main(argv=None) -> int

get_portable_builder_contract must report at least:

- ProgramName, ProgramVersion, PackageName, ManifestSchema
- ExpectedPrograms, ExpectedControls, ExpectedDependencies
- ExpectedRuntimeHostVersion == "0.5"
- DefaultGUIName == "u001_data_preparation_workbench_gui_v0_4a.py"
- Architecture == "PYINSTALLER_ONEDIR_RUNTIME_HOST_WITH_EXTERNAL_PROGRAMS_AND_CONTROLS"
- ProgramCount == 12
- ControlCount == 4
- CompanyDataIncluded == False
- RealBuildRequiredForAcceptance == True

build_release_plan is a pure planning function: it resolves and returns the
expected source/release paths and inventories but must not create, delete, copy,
execute or mutate anything.

8. CLI contract

Supported commands:

    python u001_portable_host_package_builder_v0_7.py --self-test

    python u001_portable_host_package_builder_v0_7.py --print-contract

    python u001_portable_host_package_builder_v0_7.py --build ^
      --udp001-root <UDP001> ^
      --host-source <u001_portable_runtime_host_v0_5.py> ^
      --out <new-output-directory>

The obsolete --preflight-report argument is removed. The historical preflight
described only nine programs and must not be used as release inventory authority.

Exactly one mode is required. Operational failures must print:

    U001PK04-ERROR:<stable_reason>
    C-7

and return code 7. A successful real build must print the capsule in section 15.

9. Fresh release preflight owned by v0.7

Before building, v0.7 must independently verify:

- Windows execution (os.name == "nt")
- udp001_root exists and its final directory name is UDP001
- host source exists
- output path is absent; do not accept an existing output directory
- PyInstaller importable in the current interpreter
- pandas importable in the current interpreter
- exact 12 required programs exist under UDP001\01_PROGRAMS
- exact 4 controls exist under UDP001\02_CONTROL
- every formal program compiles with Python syntax compilation
- every formal source program passes its --self-test
- runtime host v0.5 identity, contract and source self-test pass

Unexpected Python files in 01_PROGRAMS are blocking except the single allowed
legacy fallback:

    u001_data_preparation_workbench_gui_v0_3.py

The fallback is ignored and not packaged. Do not delete or modify development
root files.

10. PyInstaller policy

Preserve the accepted v0.6 strategy:

- use the current interpreter: sys.executable -m PyInstaller
- --noconfirm
- --clean
- --onedir
- --windowed
- application name U001_Workbench
- hidden imports:
  tkinter.filedialog
  tkinter.messagebox
  tkinter.ttk
- excluded modules:
  pandas.tests
  numpy.tests

Do not use --onefile. Do not use --collect-all. Do not package the 12 external
programs inside the executable. They remain visible, hashable external files.

11. Release layout

The completed output contains one folder and one ZIP built from the same staged
content:

    U001_Portable_v0_2\
      README_FIRST.txt
      _internal\
        evidence\
          u001_portable_host_package_manifest.json
          u001_portable_host_package_capsule.txt
          source and hosted self-test logs
          PyInstaller logs
      UDP001\
        00_LAUNCHER\
          U001_Workbench.exe
          _internal\...
        01_PROGRAMS\
          exactly 12 formal programs
        02_CONTROL\
          exactly 4 control CSV files
        03_CASES\
          empty

Do not include 04_TEMP, ARCH, company CAN/DBC/video/data, existing Cases, old
release files, test outputs, source datasets or analysis results.

12. Atomic build boundary

Create all intermediate build and release-stage material only below:

    <development UDP001>\04_TEMP\PK04_<timestamp>\

Do not write into 00_LAUNCHER, 01_PROGRAMS, 02_CONTROL, 03_CASES or ARCH in the
development root. Promote the staged release to --out only after every check,
hosted self-test, manifest write and ZIP creation passes. On any failure:

- do not create or alter --out
- retain failure evidence below 04_TEMP when practical
- never modify development source/control files

13. Evidence and manifest

The manifest schema is UDP001_PORTABLE_HOST_PACKAGE_V0_2 and must include:

- package identity and architecture
- CompanyDataIncluded: false
- Python version and Windows architecture
- builder source SHA256
- runtime host source SHA256 and expected version 0.5
- exact 12 Program records: relative path, Bytes, SHA256, source self-test result
- exact 4 Control records: relative path, Bytes, SHA256
- PyInstaller command without absolute company paths in the stored public fields
- frozen runtime file count and total bytes
- frozen executable Bytes and SHA256
- hosted self-test result for all 12 programs
- release-relative file inventory
- explicit acceptance boundary:
  build-PC acceptance does not replace second-PC GUI launch acceptance

Do not store absolute company paths, usernames, source dataset names, DBC names,
CAN values or case content in the portable evidence.

14. README content

README_FIRST.txt must state concisely:

- launch UDP001\00_LAUNCHER\U001_Workbench.exe
- keep the entire U001_Portable_v0_2 folder together
- 01_PROGRAMS contains 12 external, traceable program files
- 02_CONTROL contains 4 immutable control files
- 03_CASES is the local working area
- no company CAN, DBC, video, Case or result data is included
- final acceptance requires a GUI launch on a second compatible Windows PC

15. Successful real-build capsule

On a successful real build, write and print exactly:

    U001PK04
    N-R1-D1-P12-C4-H1-B1-E1-S12-Z1-M1-X0
    C-0

No real build occurs in G10D2B. This capsule is tested structurally only.

16. Self-test

--self-test must be deterministic, require no company data, no pandas operation,
no PyInstaller build and no Windows-only execution. It must cover exactly 40
assertions and print only:

    U001-PORTABLE-HOST-PACKAGE-BUILDER-V07-SELFTEST-PASS-40

It must verify at least identity, exact ordered 12-program inventory, exact
ordered 4-control inventory, package/manifest identity, pure release plan,
onedir command, no onefile, hidden imports, excludes, v0.5 host identity and
absence of the obsolete preflight-report dependency.
