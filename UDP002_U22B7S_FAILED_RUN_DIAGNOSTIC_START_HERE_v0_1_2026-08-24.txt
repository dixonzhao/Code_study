UDP002 U22B7S：V03 失败 Run 根因诊断
版本：v0.1
日期：2026-08-24

一、作用

B7R v0.3 已越过 Profile Role Count，随后 Executor 中的一个子 Module
返回 7。B7S 只读取已经保留的 Run 日志、Module Request、stdout、stderr、
Binding Profile 和 B7R failure diagnostic，自动提取最深层原因。

B7S 不重新执行 Run，不修改配置、Profile、Artifact 或任何失败证据。

二、下载与放置

下载：

u002_u22b7s_failed_run_root_cause_diagnostic_v0_1.py.txt

放到：

U-UDP002\04_TEMP

不需要移动或删除其他文件。

三、Self-test

从 C-CODE 根目录执行：

python U-UDP002\04_TEMP\u002_u22b7s_failed_run_root_cause_diagnostic_v0_1.py.txt --self-test

必须看到：

UDP002-U22B7S-SELFTEST-PASS-20 C-0

四、正式诊断

python U-UDP002\04_TEMP\u002_u22b7s_failed_run_root_cause_diagnostic_v0_1.py.txt --diagnose

五、确认输出目录

dir U-UDP002\04_TEMP\U22B7S_OUTPUT

目录中必须包含：

u22b7s_failed_run_root_cause_diagnostic.json
u22b7s_return_capsule.txt

六、回传

type U-UDP002\04_TEMP\U22B7S_OUTPUT\u22b7s_return_capsule.txt

只需原样回传三行：

B7S N-... C-0
B7SK K-... C-0
B7SD N-... C-0

若诊断器自身失败，则回传：

B7SE K-...-X1 C-7
