UDP001 REL01 - ARCHIVE THE SIX-SIGNAL PORTABLE PROTOTYPE
Date: 2026-07-27
Run environment: Windows CMD
Run location: C-CODE

PURPOSE

Preserve the existing C-0 packaging evidence while withdrawing formal Release
status.  The package is a six-signal Controlled Profile prototype and does not
contain G10 AUTO_DISCOVERY.

DO NOT delete the package, ZIP, manifest, capsule, evidence, EXE, or adjacent
runtime folder.  Move the entire release folder as one unit.

STEP 1 - CONFIRM SOURCE

dir .\UDP001\05_PORTABLE_RELEASE

If the source folder does not exist, stop and return:

REL01-SOURCE-MISSING-C7

STEP 2 - ENSURE ARCHIVE ROOT

if not exist ".\UDP001\ARCH" mkdir ".\UDP001\ARCH"

STEP 3 - MOVE THE COMPLETE RELEASE

First confirm that this destination does not already exist:

dir .\UDP001\ARCH\PK03H1_PROTOTYPE_6SIGNAL_RUNTIME_C0_20260727

If Windows reports that the destination does not exist, run:

move ".\UDP001\05_PORTABLE_RELEASE" ".\UDP001\ARCH\PK03H1_PROTOTYPE_6SIGNAL_RUNTIME_C0_20260727"

If that destination already exists, do not overwrite it.  Use:

move ".\UDP001\05_PORTABLE_RELEASE" ".\UDP001\ARCH\PK03H1_PROTOTYPE_6SIGNAL_RUNTIME_C0_20260727_01"

STEP 4 - VERIFY

dir .\UDP001\ARCH\PK03H1_PROTOTYPE_6SIGNAL_RUNTIME_C0_20260727

or, if the _01 destination was used:

dir .\UDP001\ARCH\PK03H1_PROTOTYPE_6SIGNAL_RUNTIME_C0_20260727_01

Confirm that the moved tree still contains U001_Portable_v0_1 and its ZIP,
manifest/capsule/evidence, UDP001 folder, launcher EXE, and adjacent runtime.

Do not recreate 05_PORTABLE_RELEASE now.  A new formal release will be built
only after G10A-G10C acceptance.

RETURN TO CODEX

Success:

REL01-MOVED-6SIGNAL-PROTOTYPE-C0

Failure:

REL01-FAILED-<short_reason>-C7
