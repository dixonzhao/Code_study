======================================================================
4. API REUSE CLASSIFICATION
======================================================================

Assign one InterfaceCode to each module using deterministic evidence.

0 = BLOCKED

- file missing/duplicate;
- AST parse fails;
- import safety fails;
- unbounded import-time side effect is observed.

1 = FILE_CLI_ONLY

- accepted work is exposed through CLI/file paths/fixed outputs;
- no public callable accepts an in-memory/chunk input and explicit policy/config
  while returning a result or writing through a caller-controlled sink;
- composing the stage therefore requires materializing its complete input and
  output files.

2 = REUSABLE_CHUNK_API

- at least one import-safe public callable accepts a bounded chunk/record
  iterator plus explicit policy/state;
- it does not require fixed filenames;
- caller controls output sink or receives bounded results;
- state can be passed across chunks explicitly;
- AST evidence names the callable and signature.

3 = FOUNDATION_PRIMITIVES

- reserved for M1 only;
- import-safe low-level functions exist for text-format/header parsing, DBC
  parsing and physical decode primitives;
- these primitives are reusable but do not by themselves implement the full
  Gate 2-G6 streaming chain.

M1 receives code 3 only when all required Foundation primitive groups are
present.  Otherwise it receives 0, 1 or 2 according to evidence.

For codes 2/3, evidence JSON must name the qualifying callables/signatures.
For code 1, it must name the file/CLI coupling observations.  Heuristics that
cannot establish code 2 must conservatively return code 1.

8. FRAME SHARD STRUCTURAL COUNTS
======================================================================

Gate 5/G6 currently expose, per candidate signal:

1. __value
2. __label
3. __updated
4. __update_count
5. __age
6. __valid
7. __missing_reason

Each frame shard has four leading columns:

- FrameCount
- SourceRowFirst
- SourceRowLast
- SourceUpdateCount

Calculate from the batch map:

- max candidate signals per batch;
- final-batch candidate count;
- max frame-shard column count = 4 + 7 * max batch width;
- final frame-shard column count;
- sum of all frame-shard columns;
- FrameCount must be available to every shard to preserve a common domain;
- candidate data must still partition once even if frame-key observations are
  duplicated as processing support.

Do not estimate numeric disk GB without data-row/serialization evidence.

9. DETERMINISTIC ARCHITECTURE CLASS
======================================================================

Emit EvidenceClass only; Codex makes the decision.

P1 = COMPOSE_REUSABLE_CHUNK_APIS

- M1 is 3;
- M2, M3, M4 and M5 are all 2;
- M6 is 2 or can be bypassed only by an already approved exact NONE-copy API;
- caller-controlled sinks make global long-stream files unnecessary.

- M1 is 3;
- at least one of M2-M5 is 1;
- no module is 0;
- new engine must prove equivalence against the controlled path before a full
  discovery run.

P3 = BLOCKED_REUSE_BOUNDARY

- M1 is not 3; or
- any required module is 0; or
- discovery configuration fails validation.

The probe must not implement the selected class.
