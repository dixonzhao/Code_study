U3M9C 可编辑 XLSX 图表 Module Action — 执行指南

目标
把已通过 U3M9B 验收的 Excel 导出核心接入 U003。用户通过可视化表单选择列、设置图表和保存 Profile，不需要手改 JSON；导出的折线图和数据可以在 Excel 中继续编辑。

一、文件放置

请把以下三个下载文件放到：
C-CODE\U-UDP003\04_TEMP

1. UDP003_U3M9C_EDITABLE_XLSX_ACTION_v0_1.zip
2. u003_u3m9c_xlsx_action_installer_v0_1.py.txt
3. U3M9C_START_HERE_CN_v0_1_2026-08-27.txt

不要解压 ZIP，不要修改文件名。

二、从 C-CODE 目录执行（CMD，共三条）

python U-UDP003\04_TEMP\u003_u3m9c_xlsx_action_installer_v0_1.py.txt --prepare
python U-UDP003\04_TEMP\u003_u3m9c_xlsx_action_installer_v0_1.py.txt --self-test
python U-UDP003\04_TEMP\u003_u3m9c_xlsx_action_installer_v0_1.py.txt --execute

Prepare 会自动：归档上一次 U3M9C_PREPARED、检查 ZIP 清单与哈希、检查 U003 既有运行时、检查已验收 U3M9B Core。终端会用英文逐项显示检查内容和原因。

三、安装成功标准

终端最后应同时出现：
U3M9CG1 ... C-0
U3M9CI1 N-P5-S1-G1-R1-X0 C-0

如出现 C-7，请只回传最后一条 U3M9CIE/U3M9CGE 机器码，不要自行改程序。

四、第一次界面验证

1. 正常启动 U003，并加载视频、Review Data CSV 与 Event Queue。
2. 打开 Module Manager，点击 Refresh。
3. 在 EXPORT 中选择 Editable XLSX Chart Export v0.1.0，加入并保存当前 Module Plan。
4. 返回 U003，选择一个有明确 Start/Peak/End 的 Event。
5. 打开 Module Actions，执行 Export Editable XLSX Charts。
6. 确认顶部显示当前 Event、Current FrameCount、范围和 Peak。
7. 从左侧实际 CSV 列表选择一列加入当前图；测试新增/复制图表、修改标题、颜色和 Peak 选项。
8. 保存 Profile，再重新打开同一 Profile。
9. 保持导出窗口开启，在 U003 切换到另一个 Event；确认顶部信息会跟随更新，且 U003 不会卡死。
10. 点击 Export Editable XLSX；打开结果，确认数据单元格和图表对象都能在 Excel 中修改，缺失值保持空白。

五、最短视觉回传

U3M9CV-L1-P1-E1-U1-X0-C0

L1=Module可发现并启动
P1=Profile保存/打开正常
E1=XLSX可打开且数据/图表可编辑
U1=导出窗口开启时U003仍可操作并更新位置
X0=未发现阻塞错误

如果有界面问题，请另补最多三条短 Memo；先不要修改 U3M9B Core。
