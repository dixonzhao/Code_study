1. OBJECTIVE

Build one governed parent Executor that turns one accepted U21E
RUN_PREFLIGHT_READY document and its exact U21D SOFTWARE_PLAN_READY input into
one U21A-compatible controlled Run.

The Executor must:

- verify every frozen dependency before Run creation;
- execute only the exact U21E-authorized Modules, signal bindings,
  configurations and FrameCount scope;
- run each Module in an isolated child process through frozen F2A protocol v0.2;
- commit only fully validated Artifacts whose hashes are measured by the parent;
- update Run, Stage and Module lifecycle atomically;
- apply the declared FailurePolicy without hidden continuation;
- preserve U001, plan, preflight, Module and contract immutability;
- produce a contract-valid success, partial result or controlled failure.

U21F2B is execution infrastructure. It contains no Camera/Radar algorithm,
baseline, residual, correlation, Candidate, SysID or U003 business logic.

12. CHILD WORKER ABI

The worker must:

1. validate request before importing Module code;
2. verify Module file SHA-256 equals request;
3. import exact file under a unique non-user-controlled name;
4. find exactly the declared callable and verify it is callable;
5. call it once as `result = declared_callable(request)`;
6. require a JSON-serializable mapping with allow_nan=false;
7. atomically write result inside assigned private staging;
8. validate result through promoted F2A Validator;
9. catch only at the outer boundary and emit bounded exception class, source
   basename, function and line without raw values or absolute paths.

No DataFrame, numpy object, custom class, generator or open handle crosses the
boundary. Process isolation is not an OS security sandbox.

16. construct Artifact Manifest in the parent, never accept one from Module;
17. validate Artifact Manifest through frozen Core Validator;
18. atomically move complete Artifact directory into 03_ARTIFACTS/Sx;

No partial Artifact may be registered or presented as formal output.


14. RUN/STAGE/MODULE STATES

- Run: PENDING -> RUNNING -> SUCCEEDED, PARTIAL or FAILED.
- Stages are always represented S0-S7 in order.
- a Stage with no selected Module becomes explicit SUCCEEDED no-op;
- Module SUCCEEDED only after all its Artifacts commit;
- later Stage cannot start with unresolved required dependency;
- existing Run or Artifact output is never overwritten;
- every governed JSON replacement is atomic then Core-validated;
- run_status, Run Manifest, event log and Artifact index must agree.

Successful completion requires all required Modules SUCCEEDED, every Stage
terminal, at least one validated Artifact, reconciled hashes, unchanged inputs
and no uncommitted staging presented as output.


15. FAILURE POLICY

ABORT_RUN:

- failed Module/current Stage FAILED;
- later Stages remain PENDING;
- Run FAILED; persist bounded diagnostics; stop immediately.

BLOCK_DEPENDENT_PATH:

- failed Module FAILED;
- only transitively Artifact-dependent Modules become SKIPPED;
- independent Modules continue in fixed order;
- required failure produces FAILED, optional failure produces PARTIAL.

SKIP_OPTIONAL_PATH:

- legal only for optional Module;
- failed optional Module becomes SKIPPED with reason;
- only dependent optional path is skipped;
- independent work continues;
- final Run is PARTIAL unless no requested output was lost under accepted plan.

Unexpected Executor, protocol, identity, Core contract or input-mutation error
always aborts with C-7. Never weaken a denial into a warning.


16. IMMUTABILITY AND RESOURCE BOUNDARY

- hash U001 D2-D5 before Run creation and after final child exit;
- hash plan, preflight, Promotion Evidence, Module files and configurations at
  every applicable boundary;
- never write to U001 package or modules-root;
- parent uses streamed hashes and never loads full D2;
- child stdout/stderr are file-backed and retained bytes are bounded;
- default synthetic timeout 30 seconds;
- default production timeout 600 seconds;
- default retained bytes 262144 per stream;
- persist resource limits in resolved Run evidence;
- no multiprocessing, resume or cache in v0.2.
