UDP001 CASEF1 — GUI v0.3 NEW CASE WORKSPACE ACCEPTANCE
Date: 2026-07-27
Status: CONTROLLED ACCEPTANCE BEFORE PACKAGING

======================================================================
1. PURPOSE
======================================================================

Validate the user-facing Case creation and automatic Run-path workflow before
U001 is packaged.  No decoding algorithm, Gate rule, Data Contract, or accepted
Case evidence is changed by this task.

GUI v0.3 adds:

- selection of one Raw CAN CSV, DBC Channel 1, and DBC Channel 2;
- creation of a new Case workspace under UDP001/03_CASES;
- source copies with fixed aliases CANDump.csv, DBC1.dbc, and DBC2.dbc;
- SHA-256 and physical-row evidence in u001_case_manifest.json;
- a safe positive full-source Maximum Raw rows recommendation;
- one unique Run folder containing Config, Preflight, and Output locations.

The selected original files are copied.  They are never moved or modified.
An existing Case folder is never overwritten.

======================================================================
2. NEW FOLDER CONTRACT
======================================================================

UDP001/03_CASES/<CaseID>/
  00_SOURCE-READONLY/
    CANDump.csv
    DBC1.dbc
    DBC2.dbc
  01_CONFIG/
  02_RUNS/
    <CaseID>_RUN_<timestamp>/
      00_CONFIG/u001_g8a2_config.json
      01_PREFLIGHT/
      02_OUTPUT/
  03_RETURN/
  04_EXPORT/
  u001_case_manifest.json

Config, Preflight, and Output shown by the GUI must share the same unique Run
folder.  A later Run receives a new timestamp and does not overwrite evidence.
