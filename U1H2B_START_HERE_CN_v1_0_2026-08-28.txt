U001 H2B Capability Catalog / Selection Profile 安装与验收
版本：v1.0
日期：2026-08-28

目标
----
在已验收的 U001 H1/H2/H3 基础上增加：
1. 根据当前数据源动态生成 Capability Catalog；
2. 搜索、筛选并选择本次需要解码的变量；
3. 自动显式补入 FrameCount 等强制依赖；
4. 只对选中变量执行受控流式解码；
5. 保存可复用、可审查的 Selection Profile。

重要约束
--------
- Catalog 数量来自当前数据源，可能多也可能少；不存在固定变量总数。
- Inventory 只读取结构信息，不解码 payload 数据行。
- 正式解码默认只处理显式选中变量及其强制依赖。
- 当前 WorkerCount 固定为 1；未经独立验证不得声称多线程已获批准。
- 程序按行流式读取，不允许把完整源文件一次性装入内存。

放置位置
--------
将以下三个文件直接放入：
C-CODE\U-UDP001\04_TEMP

- UDP001_U1H2B_CATALOG_SELECTION_HIGH_CODE_v1_0.zip
- u001_u1h2b_catalog_selection_installer_v1_0.py.txt
- 本说明文件

执行环境
--------
打开 Windows CMD，当前位置必须是 C-CODE。

只执行以下三条命令
------------------
python U-UDP001\04_TEMP\u001_u1h2b_catalog_selection_installer_v1_0.py.txt --prepare
python U-UDP001\04_TEMP\u001_u1h2b_catalog_selection_installer_v1_0.py.txt --self-test
python U-UDP001\04_TEMP\u001_u1h2b_catalog_selection_installer_v1_0.py.txt --execute

成功标志
--------
前两条命令必须为 C0。
最终只需回传第三条命令最后一行：

U1H2B-N5-I1-Q2-H1-A12-X0-C0

字段含义
--------
N5  = 安装 5 个可执行程序文件
I1  = Inventory 动作已验证
Q2  = Registry/Conformance 与 H2B 独立验收两道资格检查
H1  = H3 兼容性检查通过
A12 = 安装 12 个受控 payload 文件
X0  = 无失败项
C0  = 完成

运行后新增能力
------------
- adapter.py --inventory：生成当前数据源的动态变量目录。
- u001_catalog_mapping_gui_v1_0.py：可视化搜索、筛选和保存 Selection Profile。
- u001_selection_profile_compiler_v1_0.py：编译受控解码请求。

本节点只安装并验收 H2B，不要求立即使用公司真实数据执行全量解码。
