一、目标

本节点将U003从v0.5升级到v0.6：

1. 读取U002 Event Queue中的PeakFrameCount；
2. 即使两个Candidate共享同一Start/End，也保留各自独立Peak；
3. 选中Event时默认跳到Peak，仍可跳Start/End；
4. 增加Delete Selected Event；删除只影响当前会话和后续导出，不修改源CSV；
5. 主窗口标题统一为U003 Evidence Review Workbench。

七、启动U003 v0.6

python U-UDP003\01_PROGRAMS\framecount_video_reviewer_v0_6.py

按顺序操作：

1. Open Video：打开原测试视频并使用已确认的FrameCount映射。
2. Load Event CSV：选择B12的review_queue.csv。
3. Load Signal CSV：选择B12的review_data.csv。
4. 在Event列表分别选择C001、C002。
5. 每次选择后确认：
   - 右侧显示Start / Peak / End；
   - 视频自动跳到该Event自己的Peak；
   - C001/C002即使Start/End相同，Peak仍然不同；
   - Jump Peak按钮能回到对应Peak。
6. 删除功能检查：选择任一Event，点击Delete Selected Event并取消一次；确认未删除。
   如需完整检查，可删除后重新Load Event CSV，确认源CSV中的Event重新出现。

八、回传

只回传以下两行，不回传self-test行：

U003P1_RETURN_CAPSULE.txt中的U003P1行
U003P2 N-G1-E2-P2-D1-X0 C-0

含义：

G1 = GUI正常打开
E2 = C001/C002两行均独立显示
P2 = 两个Event均跳到各自Peak
D1 = 删除按钮存在、确认框正常且源CSV不被修改

失败时把对应数字改为0，X写失败项数，C-7；最多增加3条短MEMO。
