UDP002 U22B7R2：MaxAgeFrames 全角色编译修正版
版本：v0.1
日期：2026-08-24

一、为什么需要 v0.2

B7R v0.1 已正确定位并读取新的 S0 Inventory，但直接要求
MaxAgeFrames 必须已经是整数。实际 U001 Inventory 中：

HoldPolicy = NONE
MaxAgeFrames = blank

这是合法的声明式源语义，必须在 U002 配置编译层转换为：

HoldPolicy = NONE
MaxAgeFrames = 0（integer）

0 表示禁止跨 FrameCount 保持，不表示 Zero Fill。

v0.2 对全部七个已选择角色统一执行同一编译规则，不再逐变量修补。

三、Self-test

python U-UDP002\04_TEMP\u002_u22b7r_inventory_bound_profile_refresh_v0_2.py.txt --self-test

必须看到：

该 Self-test 已覆盖：

- NONE + blank -> integer 0；
- NONE + explicit 0；
- NONE + nonzero 拒绝；
- BOUNDED_HOLD + integer；
- BOUNDED_HOLD + blank 拒绝；
- fractional MaxAgeFrames 拒绝；
- unknown HoldPolicy 拒绝；
- 七个角色统一编译；
- 重复角色拒绝；
- Profile / Config 不可变重放。
