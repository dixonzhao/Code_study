1. PURPOSE

Executor v0.7 corrects the interface mismatch found in v0.6. The accepted U21E
preflight does not store runtime fields directly on each binding. Its real form is:

  SignalBindings[]
    -> Signals[]
       -> semantic fields
       -> Columns{seven exact D2 columns}

The Executor now translates that accepted structure into the frozen F2A runtime
request. It does not modify U21E and does not weaken the F2A protocol.

2. APPROVED TRANSLATION

For every manifest input port:

- CanonicalNames must match Signals[].CanonicalName exactly and uniquely.
- D3SemanticProjection is built from aligned arrays of:
  CanonicalName, CanId, Channel, MessageName, SignalName, Unit, ValueKind,
  SignalRole, HoldPolicy and MaxAgeFrames.
- D2Columns is built in the fixed Data Contract order:
  value, label, updated, update_count, age, valid, missing_reason.
- All seven Columns keys must exist and all physical column names must be unique.
- Missing, duplicate or inconsistent evidence fails closed as SIGNAL_BINDINGS.
- A module whose manifest has no RequiredInputs/OptionalInputs receives an empty
  BoundSignals array. This is intentional for artifact-only S4/S7 modules.

This resolves the earlier disagreement: SignalBindings is mandatory for a module
that declares signal input ports, but synthetic artifact-only modules must not be
forced to invent signal bindings.
