10. PROCESS CONTROL PSEUDOCODE

  require timeout finite and >0
  create Gate-owned stdout/stderr files
  record monotonic start
  start child without shell
  try:
      wait with exact timeout
      timed_out = false
  except timeout:
      timed_out = true
      terminate entire process tree
      wait only a short bounded grace
      force-kill remaining tree
  finally:
      reap root process with a bound
      close logs
  compute elapsed_ms
  read bounded tails
  return ChildOutcome

There is no retry and no second unbounded wait.
