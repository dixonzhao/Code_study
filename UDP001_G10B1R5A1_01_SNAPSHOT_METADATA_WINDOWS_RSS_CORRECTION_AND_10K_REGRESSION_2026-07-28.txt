4. WINDOWS RSS CORRECTION
======================================================================

RM0 is forbidden for an accepted Windows run.

Implement or correct the Windows standard-library measurement using:

- ctypes;
- ctypes.wintypes;
- kernel32.GetCurrentProcess;
- psapi.GetProcessMemoryInfo;
- PROCESS_MEMORY_COUNTERS_EX with c_size_t for all SIZE_T fields.

Required structure fields in order:

- cb: DWORD
- PageFaultCount: DWORD
- PeakWorkingSetSize: c_size_t
- WorkingSetSize: c_size_t
- QuotaPeakPagedPoolUsage: c_size_t
- QuotaPagedPoolUsage: c_size_t
- QuotaPeakNonPagedPoolUsage: c_size_t
- QuotaNonPagedPoolUsage: c_size_t
- PagefileUsage: c_size_t
- PeakPagefileUsage: c_size_t
- PrivateUsage: c_size_t

Set cb = ctypes.sizeof(PROCESS_MEMORY_COUNTERS_EX).  Declare function argument
and return types.  Check the BOOL return value and raise a categorized error
when it is zero.

RSS definitions:

- current RSS MB = WorkingSetSize / 1048576;
- OS peak RSS MB = PeakWorkingSetSize / 1048576;
- run peak RSS MB = max(OS peak, every sampled current RSS);
- capsule RM = round-up integer MiB, minimum 1 when supported.

Add metadata:

- RssSupported = true;
- RssProvider = WINDOWS_PSAPI;
- PeakRssMiB = positive numeric;
- PrivateUsageMiB = nonnegative numeric.

If Windows RSS initialization or any required call fails:

- RssSupported = false;
- do not print C-0 for an acceptance run;
- final error must be
  UDP001G10B1R5A1-ERROR:WINDOWS_RSS_UNAVAILABLE C-7

Do not silently catch the exception and substitute zero.

Required RSS self-tests on Windows:

- current and peak RSS are finite and >0;
- peak >= current at the same sample, allowing small race tolerance only by
  sampling peak after current;
- allocating and touching a temporary bytearray causes a measurable nonzero
  reading (do not require an unstable exact delta);
- forced provider failure returns the approved C-7 category;
- capsule formatter cannot emit RM0 when RssSupported=true.
