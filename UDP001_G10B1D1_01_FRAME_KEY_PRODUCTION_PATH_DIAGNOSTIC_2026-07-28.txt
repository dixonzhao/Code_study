4. REQUIRED STAGE COUNTERS
======================================================================

Instrument the actual production objects/functions and record:

C_CONFIG_KEY

- count of exact Required=1 Frame-key rows accepted by the production config
  loader.

R_RUNTIME_ROUTE

- count of Frame-key route objects actually placed in the production runtime
  router before source reading.

B_REQUIRED_BYTE_COLUMNS

- count of unique physical Raw byte-column names required by that runtime
  route and present in the actual pandas usecols.

P_COMPLETE_MESSAGE_ROWS

- count of source rows where all Frame-key message bytes are present and byte
  valid according to the production message-state classifier.

D_DECODED_KEY_UPDATES

- count of Frame-key updates returned by the production Foundation decode path
  before integer validation.

I_INTEGER_OBSERVATIONS

- count of decoded key values accepted as finite exact integers.

E_DISPATCHED_OBSERVATIONS

- count actually passed into the production Frame-key event/frame-state
  function.

O_OPENED_FRAMES

- number of times production state changes from no open frame to an open
  frame.

T_DISTINCT_FRAMES

- distinct accepted FrameCount values seen by production frame state.

J_FINALIZED_FRAMES

- frames the production logic would finalize, including EOF finalization in
  diagnostic dry-run state.

Additional evidence:

- resolved Frame-key CanonicalName;
- Channel, CAN_ID_Hex, SignalName and DLC;
- first three SourceRowIndex/decoded FrameCount examples at each available
  stage;
- minimum and maximum accepted FrameCount;
- decrease/conflict count;
- first zero stage code.
