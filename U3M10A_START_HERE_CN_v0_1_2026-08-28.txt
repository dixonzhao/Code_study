U3M10A 外部图片独立遮罩功能 v0.1
公司电脑执行指南

目标

在不加载视频、Review CSV或CAN数据的情况下，直接选择历史PNG/JPG/BMP/TIFF，
使用现有U003遮罩编辑器完成框选、移动、缩放、预览、撤销、Profile复用与成对导出。

本次不会删除或覆盖FrameMask v0.4.0。新版本为v0.5.0，增加第二个Action：

- Export Redacted Evidence：原有U003实时跟随模式
- Mask External Image：新增外部图片独立模式

把以下3个文件放入：
C-CODE\U-UDP003\04_TEMP

- UDP003_U3M10A_EXTERNAL_IMAGE_MASK_v0_1.zip
- u003_u3m10a_external_image_mask_installer_v0_1.py.txt
- 本说明文件

从C-CODE目录使用CMD运行三行；不要自行解压ZIP：

python U-UDP003\04_TEMP\u003_u3m10a_external_image_mask_installer_v0_1.py.txt --prepare
python U-UDP003\04_TEMP\u003_u3m10a_external_image_mask_installer_v0_1.py.txt --self-test
python U-UDP003\04_TEMP\u003_u3m10a_external_image_mask_installer_v0_1.py.txt --execute

安装成功后

1. 启动U003；不需要先加载视频或Review CSV。
2. 打开Module Manager。
3. 在EVIDENCE_VIEW中选择CameraRadar.U003.FrameMask v0.5.0并保存Plan。
4. 打开Module Actions，确认出现两个Action。
5. 选择Mask External Image并运行。
6. 选择一张可用于测试的普通图片。
7. 画一个遮罩框，检查Preview Mask。
8. 选择输出目录并执行Export Evidence Pair。
9. 确认生成original.png、masked.png和mask_profile.json。
10. 可在同一窗口点击Open Image继续处理其他历史图片；遮罩Profile几何会保留。

设计注意

- 外部图片不会被赋予虚假的FrameCount。
- 输出记录中SourceMode应为EXTERNAL_IMAGE，FrameCount应为空。
- Profile使用归一化坐标；图片布局变化后必须人工确认遮罩位置。
- 原有U003实时视频遮罩Action应继续正常显示。

如果上述视觉检查通过，只回传一行：

U3M10AV-L1-E1-P1-M1-R1-C0

其中：
L1 原有Live Action仍存在
E1 外部图片Action存在
P1 不加载视频也能打开图片
M1 遮罩预览与编辑正常
R1 三个输出文件正常生成
