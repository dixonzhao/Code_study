- exact U21D Module order is preserved;

- no Module file is imported, executed or modified.

Compare a stable projection of repeated outputs. Exclude only GeneratedAtUtc.
All other governed content must agree.


9. INDEPENDENT FAILURE MATRIX

F2  selected Module/implementation/configuration-schema hash is stale;
F3  one standard U001 package file is missing;
F4  duplicate CanonicalName exists in D3;
F5  D4 contains blocking FrameCount/package quality failure;
F6  D5 is failed/incomplete or contains an unsafe absolute/parent path;
F7  a required D2 seven-column signal group is incomplete;
F8  one RequiredInputs port is omitted;
F9  EXPLICIT CanonicalName does not satisfy its selector;
F10 ALL_MATCHES violates MinCount or MaxCount;
F11 RunScope is outside the declared frame domain or invalid EVALUATION timing;
F12 Module configuration is missing, has an illegal extra property, or uses an
    unsupported schema keyword.

Independently require exit 7, expected stable reason class and no partial
RUN_PREFLIGHT_READY output for every case.

The Gate may include extra cases but must not replace F1-F12.
