一、这一步解决什么

B12 V01 已经准确定位到：

Sequence 3 / S1 / CameraRadar.S1.RadarMeasurementValidity 0.1.0

旧模块把 U001 中所有 `Signal__age` 强制解析为整数。实际契约允许：

- signal valid = false 且 age 为空：合法，表示从未出现过有效更新；
- signal valid = true 且 age 为空：非法；
- age 非空时：必须是非负整数；
- 禁止把空 age 补成 0。

本包安装 RadarMeasurementValidity 0.1.1，并使用新 RunId 执行完整 S0-S7。
旧模块 0.1.0 和失败的 V01 Run 均保留，不覆盖、不续跑。
